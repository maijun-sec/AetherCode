# 2605.21951 MoLEM: Dynamic Mixture of Latent Memories for Self-Evolving Agents

**作者**: Dianzhi Yu 等 (CUHK + NTU + Edinburgh + SJTU + Oxford)

**日期**: 2026

**PDF**: 1.0 MB

**核心**: **MoLEM** (Mixture of Latent Memory) — 多个 expert 作 latent memory, router 选 expert, base model 冻结避免 catastrophic forgetting。

## 1. 3 大问题

- **Parametric memory**: 微调 → catastrophic forgetting
- **Retrieval memory**: 外部 DB → 模型本身未学
- **Latent memory** (本文): 内部 latent 表达 → 兼具两者优点

## 2. 框架

```
Base model (frozen)
    ↓
[Expert 1] [Expert 2] ... [Expert N]  (trainable latent memory)
    ↓
Router (key-query matching)
    ↓
Aggregated latent memory → 注入 base model
```

- 多个 expert 各带 latent memory
- Router 选 + 权重 expert
- 训练时按 stage 配 autoencoder 选 routing group

## 3. 关键数据

- Continual learning (math + science + code): 平均 +10.40% vs Vanilla baseline
- **跨训练顺序, baseline 都不一致超越** — 验证方法稳定性
- 无 catastrophic forgetting (base model 冻结)

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| Frozen base model | N/A (inference-only) | 不适用 |
| Latent memory | `MemorySnapshot` (raw, 不算 latent) | 缺 |
| Expert routing | `MultiAgentOrchestrator` (5 strategy) | ✅ |
| Continual learning | `ForgettingPolicy` (decay, 简单) | ✅ 部分 |
| Autoencoder 选 group | ⚠️ 无 ML 组件 | 缺 |

## 6. 教训

- **Latent memory 跟 external memory 互补** — 不用二选一
- **Frozen base + trainable expert** 是避免 catastrophic forgetting 的关键
- **Router 选 expert = 类似 multi-agent 路由** — 跟 AetherCode RAPS / REDEREF 思路一致
- **Autoencoder 选 group** 防止 stage 之间干扰
- **+10.40% across training order** 验证方法 robustness
- **AetherCode 偏 inference, 难完全照搬** — 概念可借鉴 (router + latent)
