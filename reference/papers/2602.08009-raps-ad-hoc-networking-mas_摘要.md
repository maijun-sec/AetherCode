# 2602.08009 RAPS: Reputation-Aware Publish-Subscribe for LLM Agent Coordination

**作者**: Rui Li, Zeyu Zhang, Xiaohe Bo, Quanyu Dai, Chaozhuo Li, Feng Wen, Xu Chen

**日期**: 2026-02-08 (v1)

**PDF**: 8.4 MB · 18 pages

**核心**: **RAPS (Reputation-Aware Publish-Subscribe)** — 把多 agent 协调类比为 ad-hoc networking, 用 intent-based pub/sub + Bayesian reputation 解决 scale + robustness。

## 1. 类比框架

| Ad-hoc networking | LLM MAS |
|---|---|
| 节点 (hosts) | Agent |
| 路由 (routing) | Agent 协调 |
| 邻居发现 | Agent 发现 |
| Trust / reputation | 信誉评分 |

**MAS 痛点 = ad-hoc networking 痛点**: 自适应 + 可扩展 + 鲁棒。

## 2. RAPS 3 层

| 层 | 作用 |
|---|---|
| **Distributed Pub-Sub substrate** | Agent 按 declared intent 交换 message, 不依赖 predefined topology |
| **Reactive Subscription** | Agent 动态 refine 自己的 intent |
| **Bayesian Reputation** | 每个 agent 有 local watchdog, 检测 + 隔离恶意 peer |

## 3. 5 Benchmark 实验

3 个 axis 一致提升:
- **Adaptivity**: 任务变化时 agent 角色自动调整
- **Scalability**: 100+ agent 不掉性能
- **Robustness**: Byzantine agent 不影响整个 swarm

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| Pub/Sub 通信 | `Blackboard` (跨 agent KV) | ✅ |
| Agent 信誉评分 | ⚠️ 当前无 reputation 机制 | 缺 |
| Byzantine 检测 | `ByzantineDetector` (R-paper-batch3) | ✅ |
| 动态 intent | `GlobalPlan.update` (GoalAct 风格) | ✅ (R-paper-batch3) |
| 100+ agent scale | ⚠️ 当前 MultiAgentOrchestrator 未压测 | 缺 |

## 5. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|
| `ReputationScore` | Agent 信誉评分 (0..1, Bayesian) | `orchestration.security` |
| `PubSubBlackboard` | 升级 Blackboard 为 pub/sub, 支持 intent-based subscription | `aethercode-bridge` |
| `IntentRefiner` | Agent 运行时动态 refine intent | `orchestration.intent` |
| `ScaleBenchmark` | 100+ agent 压测, 测性能 | `evals.scale` |

## 6. 教训

- **Ad-hoc networking 跟 MAS 高度同构** — borrow networking theory
- **Reputation + pub/sub 是 scale 关键** — 不需中心 orchestrator
- **Bayesian reputation 优于硬阈值** — 概率化更鲁棒
- **Intent-based 比 topology-based 灵活** — agent 自己决定订阅什么
- **Byzantine 防御是 MAS 基础** — 跟 AetherCode ByzantineDetector 一致
