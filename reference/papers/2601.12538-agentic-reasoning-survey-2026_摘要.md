# 2601.12538 Agentic Reasoning Survey: From Single-Agent to Multi-Agent Architectures (2026)

**核心**: 2026 LLM Agentic Reasoning 全面综述, 3 大方向: foundational / self-evolutionary / multi-agent collaborative。

## 1. 3 大方向

| 方向 | 能力 | 代表工作 |
|---|---|---|
| **Foundational** | single-agent planning / tool / search | ReAct, Reflexion, Voyager |
| **Self-evolutionary** | memory + RL 能力迭代 | Self-Refine, AutoAgent, MemoryBank |
| **Multi-agent collaborative** | 多 agent 知识共享 + 目标协调 | MetaGPT, ChatDev, AgentVerse |

## 2. 2 实现路径

| 路径 | 方法 | 优势 |
|---|---|---|
| **In-context** | 提示工程 + 结构化编排 | 便宜, 无需训练 |
| **Post-training** | RL + fine-tune | 性能优, 成本高 |

## 3. 5 大应用领域

- Scientific research
- Robot control
- Medical diagnosis
- Autonomous driving research
- Mathematical reasoning

**共同特点**: long task cycle + high feedback latency + cross-step error correction

## 4. 关键洞察

- 2026 行业从 "answer quality" pivot 到 "action quality"
- 持续 decision quality over time 是新竞争点
- Inference cost 随任务长度非线性增长
- Safety verification 复杂度指数级
- paper → product 仍有距离
