# 2608.28978 Selective Forgetting: A Graph-Based Memory Framework for Long-Term LLM Agents

**作者**: Sam Khanzad 等

**日期**: 2026

**PDF**: 1.0 MB · GitHub: skhanzad/Selective-Amnesia

**核心**: **Graph-based memory + 选择性遗忘** — 长期 memory 不能 unbounded 增长, 需 recency + frequency + structural importance 3 维剪枝。

## 1. 问题

- Long-term conversational memory 无限增长
- 检索质量下降 + 计算成本上升 + 低价值信息残留
- 现有 RAG 不支持 multi-hop + 无 forgetting 机制

## 2. 框架

```
[New interaction] 
    ↓
[Knowledge Graph] (entities + relations)
    ↓
[Selective Forgetting]
    ├─ Recency (时间衰减)
    ├─ Frequency (使用频次)
    └─ Structural Importance (图中心性)
    ↓
[Pruned Graph] → 检索
```

## 3. 关键数据

- Token F1 几乎不变 (+0.001, 95% CI [-0.015, +0.016])
- Judged correctness -1.6 points (95% CI [-0.038, +0.006])
- **结论**: 选择性 forgetting 可显著 reduce memory size, 不影响 quality

## 4. 关键洞察

- **Memory 需主动 forget** — 不只 append + retrieve
- **3 维 forgetting 策略** 互补: recency + frequency + structural
- **Graph 优于 flat RAG** — multi-hop reasoning 支持
- **Forgetting 后性能几乎不变** — 验证策略有效

## 5. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |

## 7. 教训

- **Memory 需 forget** — 不能无限 append
- **3 维互补** — 单一策略不够
- **Graph > flat RAG** — multi-hop 强
- **Forgetting 不损 quality** — 验证有效
- **跟 A-Mem 互补** — A-Mem 加新, 本文主动删
- **AetherCode ForgettingPolicy 偏简单** — 升级到 3 维
