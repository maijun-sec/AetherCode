# 2503.09572 Plan-and-Act: Improving Planning of Agents for Long-Horizon Tasks

**作者**: Lutfi Eren Erdogan, Nicholas Lee, Sehoon Kim, Suhong Moon, Hiroki Furuta, Gopala Anumanchipalli, Kurt Keutzer, Amir Gholami (UC Berkeley + UT Austin)

**日期**: 2025-03-12 (v1)

**PDF**: 1.5 MB · 44 pages

**核心**: **PLANNER + EXECUTOR** 双 agent 分离架构, 显式 step-by-step plan + 每步 dynamic replan, 解决 ReAct 单 agent 长链任务易"丢失主线"问题。

## 1. 问题

ReAct 类单 agent 在 long-horizon 任务中:
- 边思考边执行, 容易陷入局部 branch
- LLM 不擅长一次性生成完整 plan
- WebArena / WebVoyager 等长链 benchmark 准确率 < 50%

## 2. 架构

```
[User Query] → PLANNER → (plan_steps) → EXECUTOR → action → Environment
                  ↑                                ↓
                  └── replan(obs, prev plan) ←──┘
```

- **PLANNER**: 接受 query + 当前 state, 输出结构化 high-level plan (`Step 1 / Step 2 / ...`)
- **EXECUTOR**: 接受 plan + 当前 step, 输出 low-level action (e.g. `do(action="Click", element=2)`)
- **Dynamic Replan**: 每步执行后, PLANNER 重新生成 plan, 把新观察到的实体 (e.g. "John Doe") 注入后续 step

## 3. 关键贡献

| 贡献 | 说明 |
|---|---|
| Planner/Executor 显式分离 | 高层 "what to do" 和低层 "how to do" 解耦 |
| Synthetic planner data | 反向从成功 trajectory 标注 high-level plan, 用于 fine-tune PLANNER |
| Dynamic replan | 不用 static plan, 每步重新生成, 避免信息丢失 |
| **消融**: 比 ReAct 高 **+23% on WebArena-Lite** (57.58% vs 34.5%), **+13% on WebVoyager** (81.36% vs 68.2%) | |

## 4. 跟同类方法比较

| 方法 | 复杂度 | 准确率 (WebArena-Lite) |
|---|---|---:|
| ReAct (baseline) | 1 agent | 34.5% |
| AgentOccam (tree planning) | 1 agent | 45.0% |
| WebPilot | 6 agents | 51.2% |
| AdaPlanner (refiner) | 1+1 agents | 48.0% |
| **Plan-and-Act** | **2 agents** | **57.58%** |
| ADaPT (recursive decomp) | 1 agent | 53.0% |

## 7. 教训

- **Planner/Executor 分离 > 单 agent** — 避免 LLM 在 thinking/executing 之间反复切换
- **Dynamic replan > static plan** — long-horizon 必现信息丢失, 每步重生成是便宜解
- **少而精的 agent 比多而杂的 agent 强** — WebPilot 6 个 agent 不如 Plan-and-Act 2 个
- **ReAct 易陷入 local branch** — Thought-Action-Observation 太短视
