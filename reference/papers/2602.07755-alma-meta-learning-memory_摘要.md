**核心**: **ALMA** (Automated meta-Learning of Memory designs for Agentic systems) — 用 Meta Agent 搜索 memory design 代码, 替代手工设计。

## 1. 问题

- Foundation model 无状态, 限制 continual learning
- 现存 memory 设计手工固化, 不能 adapt 任务多样性和非平稳性
- 跨 domain 迁移困难

## 2. ALMA 框架

**Meta Agent** 搜索 memory design, 表示为**可执行代码** (open-ended)。
- 可以发现任意 memory design: database schemas + retrieval + update 机制
- 4 个 sequential decision-making 域实测超 SOTA 手工设计

## 3. 关键数据

| Domain | SOTA 手工 | ALMA | 提升 |

| ALFWorld | baseline | +X% | SOTA |

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| Memory as code | `MemoryPaths` + `MemoryExtractor` (Java 代码) | ✅ 部分 |
| Meta Agent 搜索 | ⚠️ 当前无 meta-learning | 缺 |
| Cross-domain transfer | `WorkingMemoryBuffer` + `TaskMemoryStore` | ✅ |
| Open-ended code space | LLM-generated code path (未实现) | 缺 |

## 6. 教训

- **Memory as code** 是有前景方向 — 把 schema + retrieval + update 都变成可执行
- **Meta-learning 跨域** 验证 transfer, 不必每个 domain 单独设计
- **Open-ended code space** 关键 — 不要预先限制 memory design 形态
- **跟 A-Mem 互补** — A-Mem 手工 5-attribute, ALMA 自动发现
