# 2506.04625 Tool-MVR: Advancing Tool-Augmented LLMs via Meta-Verification and Reflection Learning

**作者**: Zhiyuan Ma, Jiayu Liu, Xianzhen Luo, Zhenya Huang, Qingfu Zhu, Wanxiang Che (USTC + HIT)

**会议**: KDD 2025 · arXiv 2025-06-05

**PDF**: 3.5 MB · 26 pages

**核心**: **MAMV (Multi-Agent Meta-Verification) + EXPLORE (Exploration-based Reflection Learning)**, 解决 tool-augmented LLM 的 "hallucinated API call" 和 "weak reflection" 两大问题。

## 1. 问题

| 问题 | 现状 |
|---|---|
| Hallucinated API 调用 | 训练数据中大量幻觉 API call, 推理时复用 |
| 弱 reflection | **90% 以上 tool error 修不了** (ToolLLM 只有 9.1% 错误修复率) |

## 2. Tool-MVR 三件套

| 组件 | 作用 | 输出 |
|---|---|---|
| **MAMV (Multi-Agent Meta-Verification)** | 4 个 agent 协同: API 验证 / query 验证 / reasoning trajectory 验证 / 一致性验证 | 高质量指令集 **ToolBench-V** |
| **EXPLORE (Exploration-based Reflection Learning)** | "Error → Reflection → Correction" 动态学习, 利用 tool 反馈作为奖励信号 | 反射数据集 **ToolBench-R** |
| **Tool-MVR (模型)** | Qwen-7B 在 ToolBench-V + ToolBench-R 上 fine-tune | 最终模型 |

## 3. 实验

| 任务 | ToolLLM | GPT-4 | **Tool-MVR (Qwen-7B)** |
|---|---:|---:|---:|
| StableToolBench | baseline | +15.3% | **+23.9%** (vs ToolLLM) |
| API call 数量 | 1.0× | 1.0× | **-31.4%** (更高效) |
| RefineToolBench 错误修复率 | 9.1% | — | **58.9%** |

## 6. 教训

- **Multi-agent verify > single-agent verify** — 4 个 agent 各管一维 (API / query / reasoning / consistency)
- **Tool feedback 作为 reward** — 不是 RLHF 的人类反馈, 而是 tool 自身执行结果
- **错误修复率是 reflection 强弱的真实指标** — 90% 修不了 = reflection 形同虚设
- **小模型 + 强 reflection > 大模型 + 弱 reflection** — 7B + 58.9% 修复 > GPT-4 基线
