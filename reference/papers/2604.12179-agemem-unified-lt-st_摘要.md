# 2604.12179 Agentic Memory (AgeMem): Unified Long-Term and Short-Term Memory Management

**作者**: Yi Yu, Liuyi Yao 等

**日期**: 2026

**PDF**: 1.0 MB

**核心**: **AgeMem** — 把 memory management 作为 agent 可调用的 tools, 3-stage progressive RL 训练, step-wise GRPO 控制 LT/ST memory 联合调度。

## 1. 核心创新

- Memory management **暴露为 tools** (agent 显式调用)
- **3-stage progressive RL**: 基础 → 进阶 → 完整
- **Step-wise GRPO**: 每步 RL 优化 memory decision

## 2. 关键数据

- Qwen3-4B-Instruct + AgeMem: **54.31% 平均** across 5 benchmarks
- A-Mem baseline: 45.74% (AgeMem 超越 8.57 pp)
- 5 benchmarks: ALFWorld + SciWorld + PDDL + BabyAI + HotpotQA

## 3. 跟 A-Mem 对比

| 维度 | A-Mem | AgeMem |
|---|---|---|
| Memory 暴露 | 隐式 (schema) | **显式 (tools)** |
| 训练 | 无 (in-context) | **3-stage RL** |
| 优化 | Zettelkasten 启发 | **Step-wise GRPO** |
| LT/ST 联合 | 部分 | **完整** |

## 6. 教训

- **Memory as tools** 是有前景范式 — agent 显式管理 memory
- **3-stage progressive RL** 比一次性训稳定
- **Step-wise GRPO** 比 episode-level 优化粒度更细
- **8.57% 提升** 验证 memory 显式化价值
- **A-Mem (R-paper-batch3) 已有 5-attribute 框架** — AgeMem 是 training 版
- **AetherCode 偏 inference** — paper 偏 training, 概念可借鉴
