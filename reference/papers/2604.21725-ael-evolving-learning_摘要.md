# AEL: Agent Evolving Learning for Open-Ended Environments (2026)

- **ArXiv**: 2604.21725v1
- **类别**: Self-Improvement / Continual Learning
- **提交**: 2026-04

## 摘要 (中文)

LLM agent 在开放环境 (跨数百个顺序 episode) 中越来越常见, 但它们基本无状态: 每个任务都从零开始, 不把过去经验转成更好未来行为。**核心障碍不是 "要记什么", 而是 "如何使用已记的"** — 用哪种 retrieval policy, 如何解读先验结果, 当前策略何时必须改变。

AEL 是一个**双时间尺度框架**:
- **快时间尺度**: Thompson Sampling bandit 学习每个 episode 用哪种 memory retrieval policy
- **慢时间尺度**: LLM-driven reflection 诊断失败模式, 把因果洞察注入 agent 的决策 prompt — 给检索的证据一个解释框架

实验 (10 个行业板块 ticker, 208 episode, 5 个随机种子): Sharpe ratio 2.13±0.47, 超过 5 个自改进方法和所有非 LLM baseline, 同时保持 LLM-based 最低方差。

**关键消融 (9 变体) 揭示 "less is more"**: memory + reflection 一起产生 58% 累计改进 vs 无状态 baseline, 但**每个额外机制 (planner evolution / per-tool selection / cold-start / skill extraction / 3 credit assignment) 都降低性能**. 这证明: agent 自改进的瓶颈是 "self-diagnosing how to use experience", 不是架构复杂度.

## 核心观点 (给工程用的 3 条)

1. **"使用什么" > "记什么"**: 跟 R-radar-7 self-correction 的 V (verifier) 视角一致 — 不是"做什么"而是"如何验证做对". Self-improving agent 的瓶颈是 meta-cognition, 不是 memory size.
2. **Thompson Sampling bandit for retrieval policy**: 每个 episode 学习用哪种 retrieval, 这是 online test-time learning 的轻量形式 (对比 MIA 的 RL). 给 ProceduralMemory 加 bandit 选 retrieval 策略有可走路径.
3. **"Less is more" 反直觉证据**: 加 planner evolution / per-tool selection / skill extraction / 3 credit assignment → 都降低性能. 跟 R-radar-6 V 校验器一致: 不要堆 mechanism, 加 robust verifier + 简单 reflection 已经能拿到 58% 提升.
