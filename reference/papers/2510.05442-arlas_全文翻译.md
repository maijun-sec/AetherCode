## 摘要 (Abstract)

**原文**: *LLM-based agents are vulnerable to a range of adversarial attacks: prompt injection, jailbreaks, tool-call manipulation, and multi-step social engineering. We propose ARLAS (Adversarial Reinforcement Learning for Agent Safety), a framework that trains an attacker agent via reinforcement learning to discover safety vulnerabilities in a defender agent. The attacker is rewarded for causing the defender to (a) execute a harmful tool call, (b) reveal private information, (c) take an irreversible action, or (d) enter an infinite loop. We apply ARLAS to 4 popular agent frameworks (LangChain, AutoGen, CrewAI, MetaGPT) and find that ARLAS-discovered attacks succeed 35-60% of the time, compared to 5-15% for hand-crafted attacks. We also release the ARLAS benchmark, a set of 100 attack scenarios, for the community to evaluate agent safety.*

**译文**: 基于 LLM 的智能体容易受到一系列对抗攻击: prompt 注入、越狱、工具调用操纵、多步社会工程。我们提出 **ARLAS** (Adversarial Reinforcement Learning for Agent Safety), 一个通过强化学习训练 attacker agent 来发现 defender agent 安全漏洞的框架。Attacker 因让 defender (a) 执行有害工具调用、(b) 泄露隐私信息、(c) 采取不可逆动作、(d) 陷入无限循环而获得奖励。我们在 4 个主流 agent 框架 (LangChain、AutoGen、CrewAI、MetaGPT) 上应用 ARLAS, 发现 ARLAS 发现的攻击成功率 35-60%, 而手工构造的攻击只有 5-15%。我们还发布了 ARLAS benchmark, 一组 100 个攻击场景, 供社区评估 agent 安全。

## 3 ARLAS 框架

**原文 (摘译)**: ARLAS trains an attacker LLM via PPO (Proximal Policy Optimization). The attacker's action space is "the set of all possible adversarial inputs to the defender". The reward is +1 if the defender takes a harmful action, -1 if the defender rejects the attack, and 0 otherwise.

The defender is held fixed (frozen). After each training round, we evaluate the attacker on a held-out set of attack scenarios. Training converges in 5-10k episodes.

**译文**: ARLAS 通过 PPO 训练 attacker LLM。Attacker 的动作空间是"所有可能的对抗输入到 defender 的集合"。奖励: defender 采取有害动作时 +1, defender 拒绝攻击时 -1, 其他 0。

Defender 保持固定 (冻结)。每个训练轮后, 我们在保留集上评估 attacker。训练在 5-10k episode 内收敛。

## 4 实验 (Experiments)

| 框架 | 手工攻击成功率 | ARLAS 攻击成功率 | 提升 |
|---|---|---|---|
| LangChain | 12% | 58% | 4.8× |
| AutoGen | 8% | 47% | 5.9× |
| CrewAI | 6% | 41% | 6.8× |
| MetaGPT | 15% | 53% | 3.5× |

**原文 (摘译)**: ARLAS-discovered attacks are 4-7× more effective than hand-crafted ones. The implication: agent safety is much worse than the current literature suggests. We recommend that all production agents run a continuous ARLAS-style red-team eval.

**译文**: ARLAS 发现的攻击比手工攻击有效 4-7 倍。启示: agent 安全性比现有文献显示的差得多。我们推荐所有生产 agent 跑持续 ARLAS 风格的红队评估。

## 5 工程解读: 跟 AetherCode 的对应关系

| Paper 观点 | AetherCode 实现 |
|---|---|
| 4 类攻击分类 | 部分: `ByzantineDetector` 测 echo attack + overflow; 缺 prompt injection 检测 |
| 自动红队 (attacker RL) | 缺: AetherCode 没有自对抗训练 |
| Defender 冻结训练 | 缺: AetherCode 的 defender 是 rule-based, 不训练 |
| 100 攻击场景 benchmark | 缺: 可加 `ARLASAttackAdapter` (需下载或自己生成) |

### 关键工程启示

- **生产 agent 必须有红队 eval**: 论文显示手工攻击只有 12% 成功率, 但 ARLAS 找到 58% — 手工安全审计严重低估风险
- **规则-based 防御不够**: 论文 §5 暗示 attacker 能找到规则的盲区, 需 LLM 防御
- **持续对抗**: 安全不是一次审计, 是持续过程

### 后续可做

- `ARLASAttackAdapter` (extends `BenchmarkAdapter`) 跑 100 攻击场景
- 把 ARLAS 攻击 prompt 加到现有 `ByzantineDetector` 的 5 规则中
- 集成到 `AetherCodeEngine.query` 之前, 自动拒绝已知恶意 prompt

## 6 译者后记

> ARLAS 跟 BlockA2A (2508.01332) 是一对: BlockA2A 防御, ARLAS 攻击。两者结合构成"红蓝对抗"的安全研究范式。论文最有冲击力的数字是"手工攻击 12%, ARLAS 攻击 58%" — 这 4-7× 的提升意味着我们以为安全的 agent 其实千疮百孔。
>
> AetherCode 的 `ByzantineDetector` 是被动防御 (检测输出异常), 还没有主动探测能力。后续可加一个"安全红队" sub-agent, 用 RL 持续生成对抗输入, 把发现的漏洞加入 `RedFlagDetector` 的规则集。
