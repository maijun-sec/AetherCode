## 三、关键决策与教训

### 3.1 翻译工作流（5 步流水线）

1. **PDF 抽取**：`PyMuPDF (fitz)` + `pypdf`，MuPDF noisy stderr 用 `fitz.TOOLS.mupdf_display_warnings(False)` 抑制
2. **写中文翻译**：Mavis 自身作为 LLM agent 在 response 中直接生成（不调外部 LLM API；`llm_call.py` 缺真 API key）
3. **写摘要**：核心定位 / 关键论点 / 分类法 / 应用 / 挑战 / 未来方向
4. **嵌图**：按页码对应章节，在子节末尾添加图引用
5. **2 轮验证**：第 1 轮补表 + 修复；第 2 轮通读找剩余问题

### 3.2 关键决策

1. **不调外部 LLM API**：用 Mavis 自身做翻译，节省时间与成本
2. **跳过 References 章节**（用户要求），但表格 + 图表 + 全部正文都翻译
3. **技术词统一**：LLM（大语言模型）、Agent（智能体）、Multi-Agent（多智能体）、BDI（信念-愿望-意图）、guardrails（护栏）等
4. **框架名保留英文**：AutoGen、CrewAI、LangGraph、MetaGPT、Semantic Kernel、Agno、Google ADK、OpenAI Agents SDK
5. **图片按页码嵌入**：用 meta.json 找每页有哪些图，按章节对应关系插入

### 3.3 教训

1. **Picture extraction limits**：MoP (multimodal) 与 Lifelong Learning 两篇大量图是 matplotlib/PGF 矢量图，PyMuPDF 抽不到（4 张 + 5 张）。但其他论文抽取率较高（2512.13564v2 抽到 106 张）。
2. **MuPDF noisy errors**：需用 `fitz.TOOLS.mupdf_display_warnings(False)` 抑制 stderr，否则会刷屏
3. **PowerShell `&&` 不可用**：要用 `;` 或换行
4. **PowerShell 变量 `$pid` 是只读的**：用 `$paperId` 而非 `$pid`
5. **Python `IndexOf` 中文 GBK 编码问题**：用 Python 脚本而非 PowerShell `IndexOf` 处理 CJK 文本
6. **图嵌入策略选择**：对 2512.13564v2 这种 107 页大论文，每个有图页只在该页对应章节末尾插入一次（避免重复嵌入）
7. **翻译顺序按论文大小**：从最小（1 篇 8 页）开始，越大越往后，确保大论文有足够时间
