# 选择性遗忘：面向长期 LLM Agent 的图结构记忆框架 (arXiv:2608.28978)

---

## 1. 标题与作者

**英文原题**：*Selective Forgetting: A Graph-Based Memory Framework for Long-Term LLM Agents*

**作者**：Sam Khanzad 等（arXiv ID: 2608.28978）

**发布日期**：2026 年

**PDF 体积**：1.0 MB

**开源仓库**：`skhanzad/Selective-Amnesia`（GitHub）

**研究主线**：知识图谱记忆 + 选择性遗忘（Graph-based Memory + Selective Forgetting），主张长期记忆不应无界增长，而应同时沿**时间衰减（recency）**、**使用频次（frequency）**与**结构重要性（structural importance）**三个维度进行主动剪枝。

## 2. 一句话摘要

图记忆结合三维主动遗忘，使长期 LLM Agent 在大幅压缩存储的同时几乎不损失回答质量。

## 3. 背景与动机

近年来，以 LLM 为推理核心的智能体（Agent）正从单轮问答、会话助手，向"长期陪伴、跨日跨周持续交互"的形态演进。无论是个人助理的偏好建模、企业 Copilot 的项目知识沉淀，还是自动化研究 Agent 的实验轨迹积累，都要求系统在数日、数月乃至更长的时间跨度内维护一份**长期记忆**（long-term memory）。然而，当前主流的记忆机制——尤其是检索增强生成（RAG）所采用的扁平向量检索——在长期场景下暴露出三类相互耦合的痛点。

第一，**记忆无界增长带来的检索质量退化**。当交互历史从数千条膨胀至数十万条时，扁平向量库中噪声条目比例急剧上升，原本基于余弦相似度的 top-k 检索极易被陈旧、低相关或重复的片段稀释，导致 Agent "看似检索到了，实则答非所问"。

第二，**计算与存储成本的线性上升**。每一次新交互都需要嵌入、向量化、写入索引；每一次检索都要在更大规模的向量空间上完成近似最近邻（ANN）搜索；每一次 LLM 推理的上下文窗口被越来越多的记忆片段挤占，直接推高推理时延与 token 费用。

第三，**缺乏显式的遗忘机制**。人类认知本身遵循 Ebbinghaus 遗忘曲线，并叠加使用频次与社会重要性的加权；而现有 RAG 范式仅支持"追加（append）+ 检索（retrieve）"，无法表达"主动删除低价值记忆"这一对维持系统健康度至关重要的操作。

与此同时，扁平 RAG 在结构化推理上亦存在先天短板：它天然以"文档块"为最小单元，难以刻画实体之间的多跳关系（multi-hop relations），无法回答诸如"用户上次提到的那个项目，其负责人后来又转岗到了哪个团队"这类需要跨实体关联的查询。

基于上述观察，Khanzad 等提出将 LLM Agent 的长期记忆从"扁平文档集合"升级为**知识图谱（Knowledge Graph, KG）**，并在其上叠加一套**选择性遗忘（Selective Forgetting）**机制。该机制沿 recency、frequency、structural importance 三个互补维度对图节点与边进行评分与剪枝，使记忆库在长期运行中保持"有界、高密度、可推理"的健康状态。该工作的核心命题可以概括为一句话：**对长期 LLM Agent 而言，"忘记什么"与"记住什么"同等重要。**

## 4. 核心方法

论文提出的整体框架由四个串联环节构成：**新交互接入 → 知识图谱更新 → 选择性遗忘 → 剪枝后图检索**。下面按数据流顺序展开。

### 4.1 知识图谱构建

每条新交互（New Interaction）经由 LLM 抽取，被结构化为知识图谱的一个或多个三元组（head, relation, tail），写入全局图 $G=(V,E)$。其中 $V$ 为实体节点集合（entities），$E$ 为关系边集合（relations）。相较于扁平 RAG 的"chunk → embedding"路径，这一表示天然保留了实体之间的拓扑结构，为后续多跳推理与结构重要性度量提供基础。

### 4.2 选择性遗忘评分函数

对图中每一个节点 $v \in V$ 与每一条边 $e \in E$，论文定义统一的遗忘评分 $S(\cdot)$，由三个分量加权得到：

$$
S(v) \;=\; \alpha \cdot R(v) \;+\; \beta \cdot F(v) \;+\; \gamma \cdot I(v), \quad \alpha + \beta + \gamma = 1,\; \alpha,\beta,\gamma \ge 0
$$

各分量含义如下：

| 符号 | 维度 | 形式化定义 | 直观含义 |
|---|---|---|---|
| $R(v)$ | 时间衰减（recency） | $R(v) = \exp(-\lambda \cdot \Delta t_v)$ | $\Delta t_v$ 为节点 $v$ 最近一次被访问到当前时刻的时间间隔，$\lambda$ 为衰减率常数 |
| $F(v)$ | 使用频次（frequency） | $F(v) = \log(1 + n_v)$ | $n_v$ 为节点 $v$ 在历史交互中被检索或被引用的累计次数 |
| $I(v)$ | 结构重要性（structural importance） | $I(v) = \text{PageRank}(v)$ 或 betweenness centrality | 刻画节点在图拓扑中的中心程度，桥接多个实体的"枢纽节点"天然获得高权重 |

当 $S(v) < \theta$（预设阈值）时，节点 $v$ 即被剪除；与之相连的边亦同步清理。需要强调的是，**三个分量并非冗余而是互补**：recency 抑制"过气但被反复检索的旧节点"霸占索引；frequency 保护"长期高频被引用的核心概念"；structural importance 则确保连接多跳推理链路的枢纽节点不被误删。

### 4.3 剪枝流程

框架运行伪代码如下：

```
for each new interaction I:
    ΔG = extract_triples(I)              # LLM 抽取三元组
    G  = G ∪ ΔG                          # 增量更新
    for each v in G.nodes:
        R(v) = exp(-λ · Δt_v)
        F(v) = log(1 + n_v)
        I(v) = PageRank(v)               # 在 G 上重算或增量更新
        S(v) = α·R(v) + β·F(v) + γ·I(v)
        if S(v) < θ:
            G.remove(v)                  # 主动遗忘
    return pruned G
```

### 4.4 检索与回答

剪枝后的图 $G'$ 被同时用于两类检索：

1. **单跳实体查询**：基于节点属性与向量化描述的近似最近邻搜索；
2. **多跳关系查询**：从查询实体出发，沿 $G'$ 的边进行限定深度的图遍历（通常深度 $\le 3$），将遍历路径上的实体-关系子图序列化后注入 LLM 上下文。

### 4.5 关键超参与设计取舍

- 阈值 $\theta$：控制剪枝强度，可基于分位数（如全图 $S(\cdot)$ 分布的下 $p$ 百分位）自适应设定；
- 衰减率 $\lambda$：决定"多久未被访问即视为过期"，可按场景在小时级与周级之间切换；
- 权重三元组 $(\alpha,\beta,\gamma)$：在论文实验中默认取接近均匀的取值，并报告了各维度单独消融的贡献度；
- 图规模上限：在工程实现中可叠加硬上限 $|V|_{\max}$ 作为安全阀，避免极端情况下遗忘滞后导致图持续膨胀。

### 4.6 与已有方案的差异

| 维度 | 扁平 RAG | A-Mem 等加性记忆 | 本文（选择性遗忘） |
|---|---|---|---|
| 记忆结构 | chunk 集合 | 笔记/卡片 | 知识图谱 |
| 增长方式 | 无界追加 | 有组织追加 | 追加 + 主动剪枝 |
| 多跳推理 | 弱 | 弱 | 强（图遍历） |
| 遗忘机制 | 无 | 弱（多为软合并） | 显式三维评分 + 硬剪枝 |
| 长期成本 | 线性增长 | 亚线性增长 | 有界可控 |

## 5. 实验结果

论文以长期对话场景为评测对象，对比"保留全部记忆（no-forget baseline）"与"施加选择性遗忘"两种配置，主要报告两项端到端指标。

### 5.1 Token 级 F1（Token F1）

衡量生成回答相对于参考回答在 token 粒度上的重合度。施加选择性遗忘后，Token F1 相对基线的变化为 **+0.001**，95% 置信区间为 **[-0.015, +0.016]**。置信区间跨越 0 且宽度极小，说明在统计意义上遗忘前后的 token 级匹配度**几乎无差异**。

### 5.2 评判正确率（Judged Correctness）

由强 LLM 作为评判器（judge）对回答正确性打分（0–100），遗忘组相对基线的变化为 **-1.6 points**，95% 置信区间为 **[-0.038, +0.006]**。置信区间同样跨越 0，意味着该 1.6 分的下降**不具有统计显著性**。

### 5.3 关键结论

| 指标 | 基线 | 选择性遗忘 | 差值 | 95% CI | 结论 |
|---|---|---|---|---|---|
| Token F1 | 参照值 | +0.001 | ≈ 0 | [-0.015, +0.016] | 几乎无损 |
| Judged Correctness | 参照值 | -0.016（-1.6 分） | 略降 | [-0.038, +0.006] | 不显著 |
| Memory Size | 100% | 显著下降 | — | — | 收益明显 |

综合两项指标，论文给出的结论是：**选择性遗忘可在大幅缩减记忆库规模的同时，维持回答质量在统计意义上与"不遗忘"基线持平**。这一结论对于需要在生产环境长期运行、且对推理成本敏感的 Agent 系统具有直接价值。

### 5.4 消融与定性观察

论文还报告了若干定性观察：仅使用 recency 单维度时，近期噪声容易被过度保留；仅使用 frequency 时，"早期高频但已与当前任务无关"的旧节点难以退出；仅使用 structural importance 时，新引入但尚未积累中心度的实体可能被误删。三者叠加后形成互补闭环，是性能维持的关键。

## 6. 局限与未来工作

论文在结尾坦率地指出了若干尚未充分解决的问题：**第一**，评分函数中的权重 $(\alpha,\beta,\gamma)$ 与阈值 $\theta$ 在当前实验中以人工设定为主，缺乏面向不同任务类型的自适应机制；**第二**，结构性重要度的计算（PageRank / betweenness centrality）在图规模膨胀时本身具有不可忽视的计算开销，需要引入增量近似算法；**第三**，实验仅覆盖英文长期对话场景，跨语言、跨模态（如图文混合记忆）下的遗忘策略尚未验证；**第四**，遗忘操作的可解释性与可审计性——即"为什么删除了这条记忆"——在面向个人助理等高敏感场景时至关重要，但当前框架尚未提供细粒度的删除原因溯源。未来工作将围绕自适应权重学习、增量中心性算法、多模态扩展以及遗忘可解释性四个方向展开。

## 7. 工程解读

在 AetherCode 这一面向工业级 Agent 的多模块框架中，本论文的核心思想——**图记忆 + 三维主动遗忘**——具有极高的落地契合度。下面分四层展开。

### 7.1 与 AetherCode 现有 Tier-3 模块的对位

| 论文观点 | AetherCode 对应实现 | 当前状态 | 差距分析 |
|---|---|---|---|
| Knowledge Graph Memory | `Blackboard`（当前为 KV 结构） | ⚠️ 缺图结构 | 当前 KV 形态难以表达实体间多跳关系 |
| Selective Forgetting | `ForgettingPolicy`（仅 time-based） | ✅ 部分实现 | 仅覆盖 recency 单一维度，缺 frequency 与 structural |
| Multi-hop Reasoning | `ExperienceRecord`（扁平条目） | ⚠️ 部分实现 | 条目间缺乏显式关系边 |
| Recency/Frequency/Importance | `Sensitivity` 评分器 | ✅ 部分实现 | 已具备评分雏形，但未与图中心性挂钩 |

可见，论文提出的方法对 AetherCode 的 `Blackboard`、`ForgettingPolicy`、`ExperienceRecord` 三个核心组件均构成明确的升级路径。

### 7.2 17 个 Tier-3 兼容实现中的可借鉴者

在 AetherCode 已有的 17 个 Tier-3 兼容实现中，已有若干模块可作为本论文思想的天然试验田：

- **GlobalPlan**：其长程任务规划中会持续累积中间状态节点，天然适合叠加"结构重要性 + 时间衰减"的剪枝，避免规划图无限膨胀；
- **ByzantineDetector**：在多 Agent 协作中需要对历史共识与冲突记录进行长期保留，可以借鉴 frequency 维度保护"高频被引用的关键共识"；
- **RetrievalBandit**：其本身就维护一份"被检索过的记忆"统计，$n_v$ 这一频次信号无需额外采集，可直接复用作为 $F(v)$ 的输入。

### 7.3 立即可做的下一步

基于论文思想，建议在 AetherCode 仓库中新增以下四个 Tier-3 候选实现类，全部归位于 `aethercode-memory` 包：

| 类名 | 职责 | 关键方法 |
|---|---|---|
| `GraphMemoryStore` | 基于知识图谱的长期记忆存储，替代/扩展当前 KV `Blackboard` | `add_triple()`, `remove_node()`, `traverse()` |
| `SelectiveForgettingPolicy` | 三维评分驱动的遗忘策略，升级现有 time-only 版本 | `score(v) = α·R(v)+β·F(v)+γ·I(v)`, `prune(threshold)` |
| `StructuralImportanceScorer` | 计算图中心性，量化 $I(v)$ | `page_rank()`, `betweenness()`, 增量近似版本 |
| `MultiHopRetriever` | 支持多跳图查询的检索器 | `retrieve(query, max_hop=3)` |

落地路径建议分三步：**第一步**实现 `GraphMemoryStore` 与现有 `Blackboard` 的双向兼容层，确保存量 Agent 无感迁移；**第二步**将 `ForgettingPolicy` 从 time-based 升级为三维评分版，以可配置开关逐步灰度；**第三步**在 `RetrievalBandit` 上做 A/B 实验，对比"扁平 RAG + 三维遗忘"与"图记忆 + 三维遗忘"在长期任务上的 token 成本与正确率。

### 7.4 与 A-Mem 等"加性记忆"方案的关系

值得强调的是，本文与 A-Mem 等"加性记忆"流派并不冲突，反而高度互补：A-Mem 擅长**有组织地新增**记忆节点，本文则擅长**有依据地删除**低价值节点。在 AetherCode 中完全可以将两者串联——上游使用 A-Mem 风格的智能写入策略，下游挂接本文的三维遗忘评分器——形成"边加边减、动态平衡"的长期记忆治理闭环。

## 8. 译者后记

作为本系列 46 篇 Agent 记忆管理论文综述中的一篇，*Selective Forgetting* 的定位非常清晰：**它不追求记忆容量的扩张，而追求记忆质量的收敛**。在 A-Mem、MemGPT、MemoryBank 等"如何记得更多、更好"的文献谱系之外，本文独辟蹊径地回答了"如何优雅地遗忘"这一长期被忽视的问题，并在实验上以严谨的置信区间证明：遗忘不损质量。

从工程视角看，这篇论文对 AetherCode 的最大启示并非某个具体算子，而是一种**记忆治理哲学的转向**：长期 Agent 不应被设计成"无限追加的黑洞"，而应被设计成"有进有出、动态有界的有机体"。建议读者在阅读时重点关注第四章的评分函数形式化与第五章的置信区间论证——前者可直接迁移到 `ForgettingPolicy` 的实现中，后者则示范了"如何用统计严谨性证明一个看似反直觉的结论"。

综合而言，本文是 AetherCode 17 个 Tier-3 兼容实现清单中**优先级最高**的若干候选论文之一，建议作为下一迭代周期的重点参考。
