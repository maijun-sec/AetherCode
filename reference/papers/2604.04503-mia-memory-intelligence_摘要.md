# Memory Intelligence Agent (MIA) (2026)

- **ArXiv**: 2604.04503
- **作者**: Jingyang Qiao, Jingyu Gong, Kun Shao, Weicheng Meng, Xin Tan, Yu Cheng, Yuan Xie, Zhihang Lin, Zhizhong Zhang
- **类别**: Memory & Continual Learning
- **提交**: 2026-04

## 摘要 (中文)

MIA 是一种结构化记忆管理 + 持续自演化的 deep research agent。关键技术贡献:
1. **双向转换循环** (bidirectional conversion) — 非参数记忆 (vector store / file system) ↔ 参数记忆 (模型内嵌的 plan), 减少噪声干扰
2. **交替强化学习范式** — planner-executor 协作, 离线训练 + 在线 test-time 学习
3. **Reflection + unsupervised judgment** — 主动把历史轨迹转成参数化 plan, 持续更新推理时的 planner

实验结果: planner 持续更新在多模态设置上提升 3.5% 准确率, 纯文本上提升 4.15%. 小模型可以超过大模型, 工具集轻量.

## 核心观点 (给工程用的 3 条)

1. **记忆是 "双向转换循环" 不是单向存储**: param ↔ non-param, 写时压缩, 读时蒸馏. 这跟 A-Mem (2502.12110) 的双向动态链接一脉相承, 但 MIA 把 distillation 推到 "plan injection" 程度 (直接改 prompt).
2. **Online test-time learning 是关键**: 不只是训练时优化, 推理时 planner 持续更新. 这给 aethercode-memory 现有的 ProceduralMemory + GraphMemoryStore 提供 "self-evolving" 方向.
3. **工具集轻量胜于重量**: 4.15% 提升不需要大工具集, 关键在 "memory-to-plan 转换质量". 跟 Darwinian Memory (2601.22528) "survival of fittest" 思路类似.
