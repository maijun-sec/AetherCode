# 2502.12110 A-Mem: Agentic Memory for LLM Agents

**作者**: Wujiang Xu, Zujie Liang, Kai Mei, Hang Gao, Juntao Tan, Yongfeng Zhang (Rutgers + Ant Group + Salesforce Research)

**日期**: 2025-02-17 (v1, v11 latest)

**PDF**: 0.91 MB · 20 pages

**核心**: **Zettelkasten (卡片盒笔记法) 启发的 agentic memory** — 新 memory 加入时, LLM 自主生成 note + 动态发现 + 建立连接, 持续进化知识图。

## 1. 问题

| 现有 memory 系统 | 缺点 |
|---|---|
| 固定 schema (RAG / graph DB) | 预定义关系, 新场景难扩展 |
| 静态 access pattern | agent 必须在 workflow 中显式指定 read/write 时机 |
| 缺少 "evolve" 能力 | 新 memory 加入不更新旧 memory |

## 2. A-Mem 机制

**每个新 memory 包含 5 个 attribute**:
- `contextual_description`: 这条 memory 讲什么
- `keywords`: 关键词 tag
- `tags`: 分类 tag
- `embedding_vector`: 用于相似度检索
- `links`: **动态发现的相关历史 memory 指针**

**新 memory 加入流程**:
1. LLM 生成 5 attribute
2. LLM 扫描历史 memory, 找相似 (semantic / tag)
3. 双向建立 `links` 指针
4. **触发旧 memory 更新** — 旧 memory 的 contextual_description 可能要修正

**仿 Zettelkasten**: 一张张 atomic note, 通过动态 linking 形成知识网络, 没有预定义 schema。

## 3. 实验

6 个 foundation model + LoCoMo / LongMemEval benchmark 一致超越 SOTA baseline。

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| 5 attribute memory note | `ExperienceRecord` 只有 4 字段 (kind, content, score, ts) | ⚠️ 缺 tag / links |
| 动态 link 建立 | ❌ 无 | 缺 |
| 旧 memory 更新 (evolve) | `ForgettingPolicy` 只做衰减 | ⚠️ 缺 update |
| Zettelkasten 风格 | — | N/A |

## 5. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|
| `AgenticMemoryNote` | 5-attribute memory record (desc / keywords / tags / vector / links) | `aethercode-memory` |
| `DynamicLinker` | 新 memory 加入时, LLM 扫描并建立双向 links | `aethercode-memory` |
| `MemoryEvolutionPolicy` | 旧 memory 根据新 memory 触发更新, 跟 ForgettingPolicy 平行 | `aethercode-memory` |
| `ZettelkastenStore` | 无 schema 知识图, 节点 = Note, 边 = link | `aethercode-memory` |

## 6. 教训

- **Memory 必须 evolve** — 不是 append-only, 旧 memory 要随新 memory 更新
- **Schema 不能预定义太死** — LLM 自主发现 link 比人预设更灵活
- **Zettelkasten 思想适合 LLM agent** — atomic note + dynamic linking = 无 schema 知识管理
- **Memory 5 attribute (desc + tags + keywords + vector + links) 是良好结构** — 既可检索, 又可推理
