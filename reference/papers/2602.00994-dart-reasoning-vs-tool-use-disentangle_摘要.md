# 2602.00994 DART: Reasoning and Tool-use Compete in Agentic RL (Disentangled Tuning)

**作者**: Yu Li, Mingyang Yi, Xiuyu Li, Ju Fan 等 (Huawei + SJTU + THU)

**会议**: ICLR 2026 Workshop

**日期**: 2026-02-01 (v1) / 2026-05-28 (v2)

**PDF**: 3.5 MB · 17 pages

**核心**: **DART (Disentangled Action-Reasoning Tuning)** — 用独立 LoRA 分别调 reasoning 和 tool-use, 解决 ARL 中 capability interference 问题。

## 1. 问题

传统 Agentic RL 假设 reasoning + tool-use 联合训练更好, 但:

- **Capability Effect Attribution (CEA)** 量化发现: 两 capability 经常**诱导 misaligned gradient**
- 联合训练导致 training interference, 性能反而下降
- 接近 2-Agent upper bound 的最佳解是**参数解耦**

## 2. DART 框架

```
[shared LLM backbone]
    ↓
[reasoning LoRA]  +  [tool-use LoRA]
    ↓
[separated forward pass + loss]
```

- 推理 forward: 只过 reasoning LoRA
- 工具 forward: 只过 tool-use LoRA
- 独立梯度, 无 interference

## 3. 实验

13 个 benchmark (retrieval-augmented QA + NL2SQL):
- 联合 baseline: 性能饱和
- DART: 超过所有 joint baseline, 接近 2-Agent upper bound
- 简单改动 (拆 LoRA) 效果显著

## 6. 教训

- **Capability 联合训练不必然更好** — misaligned gradient 是隐藏陷阱
- **简单 LoRA 拆分 = 大改进** — 13 benchmark 普遍提升
- **CEA 提供量化诊断** — 不只定性 "感觉有问题"
- **Decoupled > 2-Agent 折中** — 共享 backbone 但独立 LoRA, 比完全 2 个模型省
- **AetherCode 偏 inference** — 这条 paper 偏 training, 概念可借鉴, 实现需 ML 背景
