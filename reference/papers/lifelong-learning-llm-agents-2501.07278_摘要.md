# 摘要：基于大语言模型的智能体的终身学习路线图

> 原文：*Lifelong Learning of Large Language Model-based Agents: A Roadmap*
> 作者：Zheng, Shi, Cai, Li, Zhang, Li, Yu, Ma（华南理工大学、MBZUAI、腾讯 AI Lab）
> 来源：arXiv:2501.07278v2 [cs.AI]，2026 年 1 月 11 日
> 原文链接：https://arxiv.org/abs/2501.07278
> 配套：https://github.com/qianlima-lab/awesome-lifelong-llm-agent

## 一、核心定位

**首篇系统综述将终身学习融入 LLM 智能体的技术**。区别于既往综述（仅 LLM + LL，或仅 LLM + Agents），本文是**唯一同时覆盖 LLM + 终身学习 + NLP + 智能体 4 个维度**的工作（表 1）。

**关键论点**：
- 现有 LLM 智能体是**静态系统**——缺乏随时间适应的能力
- 终身学习是**迈向 AGI**的关键组件——使系统能持续适应动态环境
- LLM 应被视为**环境交互的智能体**而非黑盒系统

## 二、形式化框架

### 2.1 环境建模（POMDP）

LLM 智能体环境建模为**目标条件部分可观察马尔可夫决策过程**：

$$\mathcal{E} = \langle \mathcal{S}, \mathcal{A}, \mathcal{G}, T, R, \Omega, O, \gamma \rangle$$

- $\mathcal{S}$：状态集合（多模态信息）
- $\mathcal{A}$：动作集合（自然语言指令）
- $\mathcal{G}$：可能的目标
- $T$：状态转移概率
- $R$：目标条件奖励（数值/文本）
- $\Omega$：观察集合
- $O$：观察概率函数
- $\gamma$：折扣因子

### 2.2 终身学习目标

$$\max_{\pi} \sum_{i=1}^{n} J(T^{(i)}, \pi) = \max_{\pi} \sum_{i=1}^{n} \mathbb{E}_{\tau_{T_i}^{(i)} \sim \pi} \left[ \sum_{t=0}^{T_i} \tilde{R}^{(i)}(o_t, a_t, g^{(i)}) \right]$$

**两种类型**：
- **环境内终身学习**：共享相同环境结构
- **跨环境终身学习**：跨域适应与迁移

## 三、历史发展（4 阶段）

### 3.1 1980s：基础概念建立

- 适应性控制、增量学习
- 关键概念：**灾难性遗忘** [6]、**稳定性-可塑性两难** [9]
- 早期方法：回放先前示例、调整架构

### 3.2 2010s：深度终身学习

- 深度学习兴起
- 关键技术：**EWC**（弹性权重整合）[41]、**LwF**（学习无遗忘）[42]
- **5 大方法学家族**：
  - **排练方法**（Rehearsal-Based）：回放旧数据
  - **正则化方法**（Regularization-Based）：参数约束
  - **架构方法**（Architecture-Based）：动态架构
  - **表示方法**（Representation-Based）：鲁棒表示
  - **提示方法**（Prompt-Based）：提示/辅助输入

### 3.3 2020s：LLM 终身学习

- **持续预训练**：领域语料整合
- **持续指令微调**：跨任务指令适应
- **持续对齐**：维持人类价值
- **持续知识编辑**：修复过时/错误信息

### 3.4 2023+：LLM 智能体终身学习

**关键进展**：
- **动态任务适应**
- **多模态整合**
- **记忆与知识管理**
- **强化学习整合**
- **外部知识整合**
- **更广泛真实世界应用**

## 四、三大模块架构

### 4.1 感知模块

**单模态感知**（文本为主）：
- 4.1 网页与图表环境
- 4.2 游戏环境

**多模态感知**（视觉/听觉/文本）：
- 5.1 新知识感知
- 5.2 旧知识感知（避免灾难性遗忘）

### 4.2 记忆模块（4 大类型）

| 类型 | 角色 | 关键内容 |
|------|------|---------|
| **工作记忆** | 短期/即时上下文 | 提示压缩、长上下文理解、角色扮演、自我纠正、提示优化 |
| **情景记忆** | 长期经验/事件 | 数据/特征重放、持续强化学习、自我经验 |
| **语义记忆** | 外部知识库 | 持续知识图谱学习、持续文档学习 |
| **参数化记忆** | 模型内部参数 | 持续指令微调、持续知识编辑、持续对齐 |

### 4.3 行动模块

| 行动类型 | 角色 | 关键内容 |
|---------|------|---------|
| **锚定行动** | 抽象→具体动作 | 跨模态锚定、长期一致性、不同环境解决方案 |
| **检索行动** | 拉取相关信息 | 从语义记忆检索、从情景记忆检索 |
| **推理行动** | 多步决策 | 情景内推理（CoT/ToT/ReAct）、跨情景推理 |

## 五、关键挑战

1. **稳定性-可塑性两难**：保留旧知识 vs. 适应新任务
2. **灾难性遗忘**：新任务学习导致旧知识丢失
3. **可塑性损失**：随时间失去适应能力
4. **多模态整合**：跨模态对齐的复杂性
5. **记忆管理**：长时程一致性 + 容量管理
6. **评估标准化**：缺乏统一基准
7. **真实世界部署**：安全、隐私、可靠性

## 六、未来方向

- 统一终身学习理论
- 更高效的持续学习算法
- 多模态终身学习
- 真实世界大规模评估
- 人机协作终身学习
- 安全、对齐与伦理

## 七、应用领域

终身学习 LLM 智能体在多种真实世界场景中应用：

- **游戏**：长期一致的角色行为
- **网页浏览**：适应新网站与界面
- **购物**：长期用户偏好学习
- **家居任务**：设备管理 + 多模态理解
- **操作系统**：命令适配 + 工具发现
- **机器人**：物理世界适应
- **医疗对话**：长期患者交互

## 九、对实践者的启示

1. **稳定性-可塑性平衡**是核心设计张力——避免遗忘的同时支持新学习
2. **四种记忆类型协同**：工作/情景/语义/参数化——单一记忆不够
3. **多模态整合是必由之路**——纯文本智能体无法应对真实世界
4. **持续对齐**是终身学习的伦理基础——避免价值漂移
5. **外部知识整合**（RAG、知识图谱）可有效减少参数化记忆的负担
6. **跨环境适应**是终极目标——任务从游戏 → 网页 → 机器人

## 十、核心信息

1. **终身学习是 AGI 的核心组件**——非附加功能
2. **LLM 智能体是终身学习的新前沿**——超越传统 NLP 任务
3. **三模块（感知/记忆/行动）协同**——非独立运作
4. **稳定性-可塑性两难**是根本性挑战
5. **本综述提供**首份**系统路线图**——14 个子主题 + 真实应用 + 未来方向
