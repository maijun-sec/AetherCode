# 摘要：AgentOrchestra — 层次多 Agent 通用任务框架

> **原文**: *AgentOrchestra: A Hierarchical Multi-Agent Framework for General-Purpose Task Solving*
> **作者**: Wentao Zhang, Liang Zeng, Yuzhen Xiao, Yongcong Li, Ce Cui, Yilei Zhao, Rui Hu, Yang Liu, Yahui Zhou, Bo An (Skywork AI + NTU)
> **来源**: arXiv:2506.12508v3 [cs.AI] (13 Aug 2025)
> **原文链接**: https://arxiv.org/pdf/2506.12508v3.pdf
> **PDF**: `reference/papers/2506.12508-agentorchestra.pdf` (10.7 MB)

## 一、核心问题

现有 LLM-based agent 系统缺乏:
1. **协调** specialized agents 的机制
2. **泛化**到新领域的能力
3. **plan-and-execute 静态工作流**的 rigid 限制

## 二、AgentOrchestra 架构

借鉴**指挥家** metaphor:
- **Central Planning Agent**: 分解复杂目标 + 委派 sub-task
- **Modular Agent Team**: specialized agents (programming, analysis, web nav, multimodal)
- **MCP Manager Agent**: 动态 tool 创建 + 检索 + 复用
- **Inter-agent Communication**: 显式 sub-goal 公式化
- **Adaptive Role Allocation**: 动态角色分配

## 三、关键设计

### 3.1 层次分解
```
Central Planner (high-level goal)
├── Data Analysis Agent
├── File Operation Agent
├── Web Navigation Agent
├── Interactive Reasoning Agent
└── MCP Manager Agent
    ├── Tool creation
    ├── Tool retrieval
    └── Tool reuse
```

### 3.2 通信协议
- 显式 sub-goal 公式化 (sub-goal = {id, deps, expected_output})
- Agent 间通过 sub-goal 协同
- 中央 planner 监控 progress

### 3.3 评估结果
- **GAIA benchmark test set**: 83.39% 平均分, 顶级 general-purpose agent
- 一致优于 flat-agent 和 monolithic baseline
- 跨 task 类型 (data, web, multimodal) 强泛化

## 四、对 AetherCode 的启示

### 已对齐 ✅

- **A2A protocol** (aethercode-a2a) — Agent Card + Task + streaming
- **A2A-DeepAgent bridge** (aethercode-a2a-deepagent-bridge) — 跟 deepagent 集成
- **MultiAgentOrchestrator** (orchestration.multiagent) — 3 strategy (vote/debate/critique)
- **AgentTool** / **SubagentRegistry** / **spawn_agent** tool — sub-agent 委派

### 缺 ❌

- **Central Planning Agent 抽象** — 没有"先 plan 再 dispatch"的中央 planner 类
- **Adaptive Role Allocation** — 当前 role 是静态的, 没有基于 task 特征动态分配
- **MCP Manager Agent** — 我们有 McpManager 但没有 "tool 创建 / 检索 / 复用" agent-level 抽象
