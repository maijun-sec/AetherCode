# 2505.02279 Survey: Agent Interoperability Protocols (MCP / ACP / A2A / ANP)

**作者**: Abul Ehtesham (Kent State), Aditi Singh (Cleveland State), Gaurav Kumar Gupta (Youngstown State), Saket Kumar (Northeastern)

**日期**: 2025-05-04 (v1) / 2025-05-23 (v2)

**PDF**: 4.9 MB · 20 pages

**核心**: 综述 4 个 agent 互操作协议, 提出 **phased adoption roadmap** (MCP → ACP → A2A → ANP), 是 enterprise agent ecosystem 的标准设计指南。

## 1. 4 协议对比

| 协议 | 发起方 | 时间 | 形态 | 用途 |
|---|---|---|---|---|
| **MCP** | Anthropic | 2024-11 | JSON-RPC client-server | agent ↔ tool 集成 |
| **ACP** | — | 2024 | RESTful HTTP + MIME multipart | agent ↔ agent 通信 (轻量) |
| **A2A** | Google | 2025-04 | HTTP + SSE + capability-based Agent Cards | agent ↔ agent 协作 (peer-to-peer) |
| **ANP** | — | 2025 | W3C DIDs + JSON-LD | 开放网络 agent 发现 / marketplace |

## 2. 多维对比

| 维度 | MCP | ACP | A2A | ANP |
|---|---|---|---|---|
| Interaction mode | client-server | client-server / async | peer-to-peer | peer-to-peer |
| Discovery | tool registry | runtime-independent | capability-based Agent Card | DID-based |
| Communication | request/response | MIME multipart + streaming | HTTP + SSE | JSON-LD graphs |
| Security | typed exchange | session mgmt + DIDs | capability invocation | W3C DID auth |
| Use case | tool access | structured messaging | collaborative task execution | decentralized marketplace |

## 3. Phased Adoption Roadmap

```
MCP (tool access)
  ↓
ACP (structured multimodal messaging + session mgmt)
  ↓
A2A (collaborative task execution via Agent Cards)
  ↓
ANP (decentralized agent marketplace)
```

**理由**: 从内部工具接入 → 跨 agent 通信 → 跨域协作 → 开放生态, 风险递增、可控性递减。

## 4. AetherCode 关联

| 协议 / 观点 | AetherCode 对应 | 实现状态 |
|---|---|---|

## 5. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|

| `ProtocolAdapter` | 协议路由 adapter, 自动选 MCP/ACP/A2A | `aethercode-protocol` |

## 6. 教训

- **Protocol 4 选 1 不必** — MCP+A2A 互补, 不是竞争
- **Phased adoption 降低风险** — 从 tool access 开始, 逐步扩到 marketplace
- **Agent Card 是 A2A 关键抽象** — 能力描述 + 调起方式, 是协作基础
- **JSON-RPC 是 LLM agent 通用底座** — MCP/A2A 都基于它
- **DID 是开放生态信任根** — 但门槛高, 内部系统不必上
