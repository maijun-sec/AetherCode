## 实施 (R213 T1-T9)

### T1: Module 骨架

新建 `aethercode-tui/`，注册到 parent pom：

- `pom.xml` depends on aethercode-core / -protocol / -permission / -config / -memory + Lanterna 3.1.3 + JLine 3.26.2 + jackson + picocli + slf4j + logback
- `Main.java` — picocli entry, TTY auto-detect, daemon unreachable hint
- `logback.xml` — STDERR only (TTY is STDOUT)
- parent pom 加 `<module>aethercode-tui</module>` + `<dependency>aethercode-tui</dependency>`

### T2: RPC client (复用 aethercode-protocol)

- `JsonRpcClient` — minimal JSON-RPC 2.0 over HTTP, id 自增, errors 转 `JsonRpcException`
- `DaemonClient` — typed 包装:
  - `getState / setModel / setPermissionMode`
  - `listSessions / loadSession / createSession / switchProject`
  - `sendQuery / cancelQuery / pollStream / getMessages`
  - `getPendingPermissions / respondPermission / installPermissionOverride`
  - 17 RPC methods + 1 poll 跟 desktop `rpc/queries.ts` 一一对应

### T3: 侧边栏 (Sidebar)

`Sidebar.java` — left rail，按 cwd 分组 sessions，空 cwd 进 "Unsorted" 顶部。`›` glyph 标记 currentSession。

### T4: 输入框 (InputBox)

`InputBox.java` — multiline edit，`Enter` 插入换行，`Ctrl+Enter` send。`Up/Down` 走 history，dedupe 连续相同 input。`Tab` autocomplete 留作 follow-up。

### T5: Markdown 渲染 + 流式

- `Markdown.java` — line-oriented parser：heading / paragraph / code block (```) / indented 4-space / list / quote / bold / italic / code
- `AnsiRender.java` — word-wrap + Lanterna 风格输出
- `MessageList.java` — scrollback viewer, glyph 前缀: `›` user / `●` assistant / `⚙` tool_use / `↳` tool_result / `·` system
- `AppState.appendTextDelta()` — append 到 last assistant message（没就创建），跟 desktop stream reducer 等价

### T6: Permission modal

`PermissionModal.java` — centred 7-row × 70-col 模态，4 button: 允许 / 本会话始终 / 本项目始终 / 拒绝。Left/Right 切换 focus，Enter 触发。Risk chip + 输入 preview (preferred field detection: `command` / `file_path` / `pattern` / `url` / `content`) + missingInputHint (R200 parity)。FIFO 弹出 oldest pending。

### T7: Theme + key bindings

- `ColorTheme` (record) — `dark()` + `light()`，覆盖 bg / fg / dim / accent / success / warn / danger / code / selection / border
- 跟 desktop R209 binary toggle 同 palette
- Key bindings:
  - `Enter` send / `Ctrl+Enter` newline
  - `Up`/`Down` history
  - `Ctrl+L` clear / `Ctrl+N` new session / `Ctrl+T` cycle permission mode / `Ctrl+K` palette
  - `Ctrl+C` cancel + exit
  - `Esc` 关闭 modal

### T8: Command palette + slash

- `CommandPalette.java` (Ctrl+K) — fuzzy filter by display name，↑↓ 导航，Enter 触发，+新会话 永远在底
- Slash commands: `/help /clear /new /cwd <path> /mode <ask|smart|bypass> /theme <dark|light> /exit`

## 教训 (2026-09-05)

1. **Lanterna 3.1.3 没有 `Style` interface** — 只有 `StyleSet` interface（`setForegroundColor / enableModifiers / setStyleFrom`），不要 import `com.googlecode.lanterna.Style`。`TextGraphics` 上调用 `setForegroundColor` + `enableModifiers(SGR...)` 是正路。
2. **`SGR` enum 只有 9 个值** — `BOLD / REVERSE / UNDERLINE / BLINK / BORDERED / FRAKTUR / CROSSED_OUT / CIRCLED / ITALIC`，**没有 `EMPTY` / `DIM`**。用 `EnumSet.noneOf(SGR.class)` 当 "no modifiers"。
3. **`TextColor.ANSI` 字段名是 `_BRIGHT` 不是 `BRIGHT_`** — `ANSI.BLACK_BRIGHT` 不是 `ANSI.BRIGHT_BLACK`。
4. **`TextCharacter.withModifiers(Collection<SGR>)` 接 `Collection` 不是数组** — 用 `EnumSet<SGR>` 直接传。
5. **record 字段是 private final**，外部访问用 accessor `fieldName()`，不能 `obj.fieldName`。
6. **Java R213 用 Lanterna 直接渲染**最简单 — 不用 ANSI escape 自己写 STDOUT（Lanterna 在 alternate screen 模式下会拦截写入，混用容易冲突）。
7. **TTY auto-detect 用 `System.console() != null`** — R20-A 的判定方式，CI / IDEA plugin host 都不是 TTY，自动 fallback 到非交互模式。
8. **JSON-RPC polling 200ms** 间隔是经验值 — 太短浪费 CPU，太长 user 觉得卡。permission_request 通知需要 <500ms 响应，所以 poll 间隔 200ms 是合理选择。
9. **stream_event text_delta 累加到 last assistant message** — 不要每次 text_delta 都创建新 message，否则 transcript 会爆。`AppState.appendTextDelta` 是 desktop stream reducer 的等价物。
10. **R20-A 是 TUI 设计决策文件** (parent pom 加 lanterna.version 3.1.3)，但实际 TUI 实现 R95-C retire 后没继续。R213 是从 0 重建，跟 R20-A 决策一致但不是从 R20-A 代码继续。
