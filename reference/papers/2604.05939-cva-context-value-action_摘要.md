# 2604.05939 CVA: Context-Value-Action Architecture for Value-Driven LLM Agents (PKU 北大)

**作者**: TianZe Zhang, Sirui Sun, Yuhang Xie, Xin Zhang, Zhiqiang Wu, Guojie Song (北大)

**会议**: Findings of ACL 2026

**日期**: 2026

**PDF**: 1.0 MB

**核心**: **CVA (Context-Value-Action)** — 基于 S-O-R model + Schwartz 价值观理论, 解耦 action 生成 vs 认知 reasoning, 用 Value Verifier 显式建模 dynamic value activation。

## 1. 问题

- LLM-as-judge 评估有 self-referential bias
- Prompt-driven reasoning 强度增加反而加剧 value polarization
- Population diversity 坍缩

## 2. 3 阶段架构

| 阶段 | 角色 |
|---|---|
| **Context** | 历史 observation 输入 |
| **Value** | 显式建模 dynamic value activation (跟 Schwartz 10 basic values) |
| **Action** | 选最 align 当前心理状态的 candidate action |

**核心创新**: 用真实 human data 训 Value Verifier, 不靠 LLM 自我验证

## 3. 关键数据

- **CVABench**: 110 万+ real-world interaction traces
- 显著 outperform baselines
- 缓解 polarization + 行为 fidelity + 可解释性 3 维度

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| 行为 fidelity 评估 | R-eval 全覆盖 | ✅ |
| Value Verifier | `Verifier` 偏功能性, 不评估 value | 部分 |
| Schwartz 价值观 | ⚠️ 缺 | 缺 |
| S-O-R 行为模型 | ⚠️ 缺 | 缺 |
| LLM-as-judge 局限 | R-eval-1/4/5 注意 self-bias | ✅ |

## 5. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|
| `ValueVerifier` | Schwartz 价值观维度的 verifier | `orchestration.verifier` |
| `HumanBehaviorEvaluator` | 行为 fidelity 评估, 不靠 LLM 自我评估 | `evals.behavior` |
| `PolarizationDetector` | 检测 population diversity 坍缩 | `evals.diversity` |
| `BehavioralDataset` | 真实 human interaction traces | `evals.data` |

## 6. 教训

- **LLM-as-judge 有 self-bias** — 不能完全依赖
- **Value Verifier 用 human data 训** — 显式化避免 prompt 偏差
- **S-O-R 模型** 是认知心理学的根基
- **Schwartz 10 values** 是经典框架, 可借鉴
- **行为 fidelity 是新维度** — 跟 task success 互补
- **CVABench 110 万+ 数据** 公开可用
