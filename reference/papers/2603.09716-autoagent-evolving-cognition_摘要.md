# 2603.09716 AutoAgent: Evolving Cognition and Elastic Memory Orchestration

**作者**: Xiaoxing Wang, Ning Liao 等 (MemTensor + 上海交大 + Shanghai Advanced Algorithms)

**日期**: 2026-03

**PDF**: 1.5 MB · 18 pages

**核心**: **3 大组件** — Evolving Cognition / On-the-fly Decision / Elastic Memory, 形成 self-evolving 多 agent 框架, 闭环 cognitive evolution 无需外部 retrain。

## 1. 3 组件

| 组件 | 作用 | 实现 |
|---|---|---|
| **Evolving Cognition** | 每个 agent 维护 prompt-level cognition (tools / self / peer / task) | 结构化 prompt 持续 update |
| **On-the-fly Decision** | 实时 context 决策, 统一 action space (tool call / LLM / inter-agent) | runtime router |
| **Elastic Memory Orchestrator** | 动态组织 history: 保留 raw + 压缩冗余 + 提取 episodic abstraction | 三档 memory |

## 2. Closed-loop Cognitive Evolution

```
Intended action → Observed outcome → Update cognition → Expand reusable skills
       ↑                                                            ↓
       └──────────────── Next decision uses updated ←──────────────┘
```

**关键**: 无需外部 retrain, 在 prompt-level 进化, 节省成本。

## 3. 实验

- Retrieval-augmented reasoning
- Tool-augmented agent benchmark
- Embodied task environments
- **3 类一致超过 static + memory-augmented baseline**

## 6. 教训

- **Cognition 4 维是结构化基线** — tool / self / peer / task 缺一不可
- **Closed-loop evolution 不用 retrain** — prompt-level 进化成本低
- **Elastic memory 三档是关键** — raw + compressed + episodic 平衡
- **Unified action space 简化路由** — tool / LLM / inter-agent 同一 action space
- **AetherCode 已覆盖大部分** — 仅缺 CognitionEvolver 显式类
