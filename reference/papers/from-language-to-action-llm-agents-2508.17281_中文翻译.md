## 摘要

对人类水平人工智能（AI）的追求显著推动了自主智能体与大语言模型（LLM）的发展。LLM 如今被广泛用作决策智能体——因其**解释指令、管理顺序任务、通过反馈适应**的能力。本综述考察了将 LLM 用作自主智能体与工具使用者的最新进展，包含**七个研究问题**。我们仅采用 2023–2025 年间发表在 A* 与 A 级会议和 Q1 期刊的论文。提供对 LLM 智能体**架构设计原则的结构化分析**——将其应用划分为**单智能体与多智能体系统**，并讨论**集成外部工具的策略**。此外，还研究了 LLM 的**认知机制**（包括推理、规划与记忆），以及**提示方法与微调程序对智能体性能的影响**。进一步，我们评估了**当前基准与评估协议**，并对 **68 个公开可用数据集**进行了分析，以评估基于 LLM 的智能体在各种任务中的性能。在本综述中，我们识别了关于 LLM **可验证推理**、**自我改进能力**以及**基于 LLM 智能体个性化**的关键发现。最后，我们讨论了**十个未来研究方向**以克服这些空白。

## 1. 引言

大语言模型（LLM）已成为人工智能（AI）研究的核心——因其**类人的理解、生成与自然语言推理能力** [1, 2]。LLM 最初被用作更大应用内的**文本生成器或理解模块**。然而，少样本提示 [3]、思维链（CoT）提示 [4] 与自问提示 [5] 等技术展示了如何通过智能提示与输入模式设计来提升 LLM 的潜力。

超越传统自然语言处理（NLP）任务，**LLM 如今充当自主智能体与智能工具**——它们被嵌入越来越复杂的工作流中，在各种真实应用中执行规划、决策与工具交互——包括**研究助手 [6]、软件开发 [7]、药物发现 [8]、多机器人系统 [9]、临床支持 [10]、游戏仿真 [11] 与科学仿真 [12]**。

**作为智能体的 LLM** 可**观察环境、做出决策并采取行动**。在此范式中，单智能体 LLM 系统在决策任务中展现了有前景的性能。**Reflexion [13]、Toolformer [14] 与 ReAct [15]** 等单智能体系统展示了模型如何在涉及规划、记忆与工具使用的决策循环中运行。然而，它们**在需要同时上下文跟踪、外部记忆集成与自适应工具使用的动态环境中常常挣扎** [16, 17]。

为应对这些局限，**多智能体 LLM 系统**的概念获得了越来越多的关注。在此类系统中，多个 LLM 作为专门化智能体交互——每个具有不同角色或目标——协作解决单一智能体无法管理的更复杂任务。通过结构化通信、反思推理与模拟环境中的显式角色分配，**多智能体 LLM 展现出共识构建、感知不确定性的规划与自主工具交互**等能力 [18–20]。

**MetaGPT [21]、CAMEL [22]、AgentBoard [23]、AutoAct [24] 与 ProAgent [25]** 等示例展示了协作智能体如何执行角色特定指令与协调规划——而**Generative Agents [12]** 在交互环境中模拟类人行为。

鉴于 LLM 作为智能体与工具的**巨大潜力**，**理解其演进角色的需求已变得强烈**。因此，**对其最新进展的系统综述、对剩余空白的讨论与未来研究方向**对推进该领域至关重要。

**本综述的关键贡献**：
- **对将 LLM 用作智能体与工具使用者的最新进展进行全面综述**——采用明确分类法描述其架构、框架与交互范式
- **考察 LLM 推理、规划与记忆能力**——分析提示、微调与记忆增强如何提升智能体化性能
- **批判性综述当前评估方法与基准**——用于 LLM 智能体与工具使用者
- **识别根本性挑战**（对齐、可靠性与泛化）——并勾勒有前景的研究路径以提升 LLM 智能体的鲁棒性与智能性

## 4. 智能体框架的基线 LLM

LLM 智能体的架构与功能**从根本上与其底层语言模型相关** [10, 32, 123]。所选基础模型最终决定智能体的**可达到性能水平、相关成本与适配灵活性** [31, 105, 123]。我们的发现揭示了**专有模型的广泛使用**与**竞争性开源模型日益增长的使用** [41, 68, 87, 95, 104]。

### 4.1 专有 LLM 用于智能体化应用

**GPT 家族**（特别是 **GPT-4 及其变体**）仍是智能体实现**最广泛采用的基础** [104]——作为核心决策组件或评估新技术的参考基线。

- **约 55 项研究**使用 GPT-4 或其变体
- **约 23 项研究**使用 GPT-3.5
- 其他变体：Code-DaVinci-002、Text-DaVinci-003、GPT-2、o1-preview、o1-mini

**Claude 模型家族**（Anthropic）：Claude 3 Opus、Claude 3.5/3.7 Sonnet、Claude 2、Claude 1——以**超长上下文、安全优先对齐、强指令遵循**著称。

**Google DeepMind**：Gemini 1.0 Pro、Gemini 1.5 Pro、PaLM 2、FLAN-T5——以**原生多模态、百万 token 上下文、谷歌生态集成**著称。

**其他**：Mistral-medium-2312、Chinchilla-LM (70B)、HyperCLOVA (82B)——以**推理高效小模型、数据高效扩展**著称。

### 4.2 开源 LLM

开源 LLM 在智能体研究中获得**越来越重要的地位**——因其**可访问性、可复现性、成本效率与本地部署的可行性**。开源模型包括 LLaMA 系列、Mistral 系列、Qwen、DeepSeek、Baichuan、ChatGLM 等——在低成本、本地化、隐私保护场景中具特殊价值。

## 5. 跨 LLM 智能体的外部工具集成

**外部工具的集成**是从"语言模型"到"行动智能体"转变的关键。本节讨论 LLM 智能体如何通过三种主要工具集成模式与外部世界交互：**知识锚定与检索、代码生成与 API 使用、交互与具身环境**。

### 5.1 知识锚定、网页搜索与结构化检索

LLM 的内在知识受限于训练数据且容易产生**幻觉**。**检索增强生成（RAG）**通过将 LLM 响应锚定到外部知识源缓解这些问题：

- **简单检索** → **迭代检索** → **多智能体协作检索** 的演进
- **知识图谱、向量数据库、网页搜索**作为外部锚定
- **Agentic RAG**：多个智能体协作决定检索哪些源、评估质量、迭代精炼 [7]

### 5.2 代码生成、API 使用与系统级集成

代码生成与 API 使用是 LLM 智能体的**核心行动能力**——使智能体从"文本响应者"转变为"行动执行者"：

- **Codex、Code-DaVinci-002、GitHub Copilot**：代码生成
- **Toolformer** [14]：自监督学习何时调用 API（计算器、搜索引擎、翻译工具）
- **MRKL 框架**：模块化工具路由
- **API 集成**：LLM 通过结构化接口与外部系统通信（数据库、CRM、企业系统）

### 5.3 交互与具身环境

LLM 智能体在**物理与虚拟具身环境**中表现出强大的交互能力：

- **机器人**：SayCan、PaLM-E、RT-2 —— 自然语言指令 → 物理动作
- **多智能体游戏**：Diplomacy、Cicero —— 战略推理 + 协商
- **VR/AR**：自然用户界面（手势、语音）
- **WebArena、OSWorld**：GUI 操作智能体

- **LLM 核心**：决策引擎（GPT-4、Claude、Gemini、LLaMA 等）

## 7. 推理、规划与记忆

### 7.1 推理（Reasoning）

推理是 LLM 智能体的**核心认知能力**——包括：

- **基础推理**：CoT（思维链）、自一致性、Zero-shot CoT
- **高级推理**：ToT（思维树）、GoT（思维图）、CoT-SC（自一致性）
- **结构化推理**：逻辑推理、因果推理、对比推理
- **工具增强推理**：与外部计算器、知识库结合

### 7.2 规划（Planning）

规划将复杂目标分解为可执行步骤：

- **任务分解**：HTN（层次化任务网络）、ToT
- **子目标生成**：CoT-SC、子目标分解
- **规划-执行循环**：Plan-and-Execute、ReAct
- **反思式重规划**：Reflexion、Self-Refine
- **多智能体规划**：跨角色协调

### 7.3 记忆（Memory）

记忆是 LLM 智能体的**关键支撑**——使智能体能跨交互保留信息：

- **短期记忆**：上下文窗口（受限于 token 限制）
- **长期记忆**：外部向量数据库、知识图谱
- **情景记忆**：过去事件的详细记录
- **语义记忆**：抽象知识与概念
- **程序性记忆**：技能与动作模式

**G-Memory**（三层图：洞察图、查询图、交互图）[14] 与 **CAIM**（Memory Controller + Memory Retrieval + Post Thinking）[12] 等是高级记忆架构的代表。

---

## 8. 提示、微调与记忆增强

### 8.1 提示工程（Prompt Engineering）

提示工程是**无需重训练即可提升智能体性能**的核心方法：

- **基础提示**：Zero-shot、Few-shot
- **推理提示**：CoT、Self-Ask、ReAct
- **结构化提示**：模板化指令、JSON schema
- **元提示**：让 LLM 自我生成或优化提示

### 8.2 微调（Fine-Tuning）

微调通过**针对特定任务调整模型参数**提升智能体能力：

- **监督微调（SFT）**：对标注轨迹的学习
- **RLHF**：从人类反馈的强化学习
- **DPO**：直接偏好优化
- **工具使用微调**：Toolformer 风格的工具轨迹学习
- **轨迹微调**：以智能体执行轨迹为中心

### 8.3 记忆增强（Memory Augmentation）

记忆增强**弥补上下文窗口的局限**：

- **RAG**：检索增强生成
- **长上下文模型**：百万 token 窗口
- **外部记忆系统**：MemGPT、向量数据库
- **分层记忆**：活动 + 中期 + 长期

### 8.4 协同集成

**提示 + 微调 + 记忆**的协同集成是现代 LLM 智能体性能最大化的关键。

## 9. 评估与基准

LLM 智能体评估的范式发生根本转变——从"静态准确率"转向"动态过程导向"方法学。本综述系统考察了**任务导向基准、评估方法学、以及 68 个公开可用数据集**——旨在捕捉真实场景中智能体的推理质量、适应性与任务完成。

### 9.1 任务导向与交互式基准

传统 Q&A 基准无法揭示 LLM 智能体在长程规划、工具管理、自然交互方面的能力。LLM 智能体需要面向**真实任务复杂性**与**多模态性质**的评估套件。

**核心评估基准（按应用领域）**：

| 基准 | 评估维度 | 应用领域 | 关键能力 |
|------|---------|---------|---------|
| **AgentBench** | 多环境 LLM 智能体综合能力 | 综合 | 跨环境代码生成、网页浏览、网络购物、操作系统、数据库操作、横向思维谜题等 |
| **WebArena** | 真实网页环境端到端成功率 | 浏览器操作 | 在真实网站（购物、地图、社交、GitHub 等）完成任务 |
| **ToolBench** | 工具选择 / 参数 / 执行可靠性 | 工具密集型 | 真实 API 调用正确性、参数 schema 合规性 |
| **SWE-bench** | 软件工程问题端到端解决 | 编码 | GitHub issue 解析 + 跨多文件代码生成 + 测试通过 |
| **GAIA** | 通用助手 + 短可验证答案 | 通用 | 多步推理 + 工具使用 + 信息检索 |
| **MINT** | 多轮工具使用 | 多轮交互 | 多步决策、自然语言反馈整合 |
| **τ-bench** | 多领域工具使用 | 跨域 | 真实场景多工具组合 |
| **HumanEval** / **MBPP** | 代码生成 | 编程 | 函数级 Python 代码正确性 |

**关键发现**：静态 Q&A 基准无法捕捉**长程推理、复合错误、工具可变性**等智能体核心能力——必须采用**任务导向、交互式、长程**评估。

### 9.2 评估方法学与指标

LLM 智能体的评估需要**多维度指标体系**，覆盖客观性能与主观体验。

**核心指标**：

| 指标类别 | 具体指标 | 测量方法 |
|---------|---------|---------|
| **任务性能** | 任务成功率、分数/奖励、完成时间、步数 | 端到端执行跟踪 |
| **效率成本** | 延迟（中位数 + p95）、token 使用、API 成本 | 基础设施日志 |
| **工具使用** | 工具选择准确率、参数正确性、工具执行成功率、恢复率 | 工具调用跟踪 |
| **轨迹质量** | 动作有效性、循环率、规划遵循 | 逐步状态对比 |
| **鲁棒性** | 扰动下成功率、最坏情况成功率、方差 | 多种子多次运行 |
| **安全合规** | 策略违规率、人工干预率、每步干预次数 | 审计日志 |

**公式化指标**（论文公式 5-23）：如 **SuccessRate** = (1/N) Σ s_i、**ToolSelAcc** = 工具选择准确率、**RecoveryRate** = 工具失败后任务恢复率、**WorstSuc** = 最坏情况成功率等。

### 9.3 智能体训练与锚定数据集

本综述系统分析了 **68 个公开可用数据集**——按用途分类：

- **推理数据集**：GSM8K、MATH、HARP、ARC、LogiQA、HotpotQA
- **问答与对话**：Natural Questions、TriviaQA、CoQA、QuAC、SQuAD
- **工具使用**：ToolBench、API-Bank、ToolQA、Glaive Function Calling
- **代码生成**：HumanEval、MBPP、CodeContests、APPS、RepoBench
- **多模态**：MMMU、MM-Vet、SEED-Bench、MathVista、Video-MME
- **个性化**：PersonalDialog、PERSONA-CHAT
- **安全与对齐**：Anthropic HH-RLHF、BeaverTails、AdvBench

**数据集分析维度**：任务类型、模态、领域、规模、评估方法、典型应用。

## 10. 讨论

### 10.1 关键发现

- **单智能体系统**优先考虑**自主性与内省决策**；**多智能体系统**聚焦**协调、角色分布与协作规划**
- 这种区分**具有领域敏感性**——多智能体在**需要社交智能、协作问题求解、高风险决策支持**（医疗、科研、复杂工程）的领域展现显著优势
- **集成外部工具、实时数据源与多模态系统**已成为**使 LLM 智能体能执行超越预训练模型局限的任务**的关键
- **评估**正从**静态准确率基准**转向**动态过程导向方法**——考虑真实环境中的推理质量、适应性与任务完成

### 10.2 关键局限与安全考虑

- **安全风险**：安全威胁、后门攻击
- **性能局限**：长时程、动态环境中的失败
- **个性化挑战**：动态或个性化设置中的适应性
- **信任与可解释性**：难以追踪决策路径
- **智能体共进化**：多智能体系统的复杂交互可能产生意外行为

### 10.3 任务导向与方法学数据集

针对**任务导向**（推理、规划、工具使用）与**方法学**（记忆、反思、自我改进）的研究日益结合——形成**过程导向评估**的新范式。

## 11. 未来研究方向

### 11.1 朝向可验证推理与鲁棒自我改进

未来工作应聚焦于**两个关键目标**：(1) **使智能体推理透明且可验证**，(2) **开发不损害安全的可靠自我改进方法**——这些能力对**错误可能产生严重后果的高风险环境**至关重要。

**可验证推理**方向：
- **过程奖励模型**（如 FG-PRM）—— 训练奖励模型识别与惩罚数学推理错误
- **自验证与对抗性测试**—— 智能体在输出前自检逻辑一致性
- **结构化证明与形式化验证**—— 集成自动定理证明器

**强自我改进**方向：
- **Reflexion**（口头强化学习）—— 智能体反思性能并从错误中学习
- **RISE**（递归内省微调）—— 持续自校正的微调过程
- **CORY**（pioneer-observer 协作 RL）—— 避免传统 RL 微调中的策略失败
- **COPPER**（反射器智能体）—— 系统化自我改进循环
- **AgentOptimizer** —— 将工具视为可学习参数
- **AVATAR** —— 通过比较器模块自动化工具提示优化

### 11.2 朝向可扩展、自适应与协作的 LLM 智能体系统

未来研究应提升 LLM 智能体的**可扩展性、适应性与实时运行能力**——用于多模态与领域特定环境部署。

**关键优先方向**：

1. **基础设施改进**：
   - KV 缓存与优化解码器
   - 边缘硬件部署（轻量级智能体）
   - 流式交互的低延迟架构

2. **多智能体协作增强**：
   - 人类启发的社会基础对话策略
   - 上下文感知与意图推断
   - 用于交通、仓库、无人机的轻量级智能体

3. **协商密集型仿真**：
   - Lewis-style 协调游戏
   - Diplomacy（战略协商 + 欺骗检测）
   - 多智能体紧急情况的推理评估

4. **开源基础**：
   - LLaMA-2-70B 等可访问、可扩展、可复现的开源基础
   - 集体开发安全、有效的社会对齐智能体系统

5. **应用扩展**：
   - 基于手势的接口
   - EHR 预测（医疗）
   - 协作游戏
   - 持续学习 + 协同进化训练
   - 提示精炼方法

### 11.3 深化人机共生：个性化、主动性、信任

未来研究应增强 LLM 智能体在**复杂、动态、开放、高风险环境**中的**自主性、对齐性、实际可部署性**——平衡**建设性自主**与**安全性约束**。

**核心方向**：

1. **长期个性化**：
   - 持久、演化的用户模型
   - 隐私保护（PrivacyAsst 等）
   - 跨多模态接口对齐

2. **意图识别与共创交互**：
   - 上下文敏感对话（"Tell Me More" [63]）
   - 共创任务精炼（ReHAC [98]）

3. **伦理与社会风险**：
   - 拟人化与过度信任
   - 弱势群体（儿童、老人）的敏感信息保护
   - 道德责任归因的"问责鸿沟"

4. **安全防护**：
   - 抵御越狱（jailbreaking）攻击
   - 环境信号触发的后门攻击检测
   - 多轮对话与多源信息下的鲁棒性

5. **持续优化**：
   - 协同解码
   - 轻量级模块化执行
   - 高效缓存机制
   - 集成能力：技术熟练 + 伦理对齐 + 情感感知 + 隐私保护

**最终愿景**：智能体在复杂工作流中**有意义的整合**——超越纯技术能力。

## 12. 结论

本文对**基于 LLM 的智能体及其工具集成**进行了全面综述。我们考察了**提示工程、微调、记忆增强与工具使用**如何通过回答**七个聚焦的研究问题**来促成 LLM 智能体的构建。

我们观察到**单智能体系统**优先考虑**自主性与内省决策**。然而，**多智能体系统**聚焦**协调、角色分布与协作规划**。**关键的是，这种区分具有领域敏感性**——多智能体配置在需要**社交智能、协作问题求解与高风险决策支持**（如医疗、科研与复杂工程任务）的领域展现显著优势。**集成外部工具、实时数据源与多模态系统**已成为使 LLM 智能体能**执行超越预训练模型局限的任务**的关键。与此并行，这些智能体的**评估正从静态准确率基准转向动态过程导向方法**——这些方法考虑真实世界环境中的**推理质量、适应性与任务完成度**。

我们还考察了 LLM 智能体部署于敏感环境时的**关键局限与安全顾虑**。这些包括**安全风险、性能局限、在动态或个性化设置中的适应性，以及信任、可解释性与智能体共进化的挑战**。**应对这些挑战将确保未来应用中的可靠性、信任与效率**。

在我们看来，**未来工作应聚焦于两个关键目标**：(1) **使智能体推理透明且可验证**，(2) **开发不损害安全的可靠自我改进方法**。这些能力在**错误可能产生严重后果的高风险环境**中至关重要。**确保 LLM 智能体值得信任、有韧性、且与领域特定要求对齐，将是其跨学科负责任部署的核心**。
