# R109-3-SYNC: TUI ↔ Desktop sync (2026-08-13)

## TL;DR

The TUI standalone (`ac-tui-standalone.exe`) and the desktop app's
Settings → Agents tab now surface the same agent model-binding
information. Two new TUI slash commands, `/agents` and `/agent <name>`,
mirror the desktop's AgentsPanel list and AgentEditorLazy detail view.

## What ships

| TUI command | Desktop equivalent | Purpose |
|-------------|-------------------|---------|
| `/agents` | Settings → Agents tab list | List Mavis agents with model column |
| `/agent <name>` | AgentEditorLazy (open agent) | Show body + frontmatter (model, description, displayName) |

## Wire shape (unchanged from R109-3)

`listAgents` and `getAgentBody` return the same shape on the wire for both
TUI and desktop:

- `listAgents()` → `{ok, count, agents: [{name, description, displayName,
  model, lastModifiedMs}, ...]}`
- `getAgentBody({name})` → `{ok, name, body, path, description,
  displayName, model, lastModifiedMs}`

`model` is empty string for agents without an explicit binding (legacy
R107-B agents). Both surfaces show `(default)` / `(engine default)` in
that case.

## TUI rendering

`/agents` produces a `sideNote` of kind `"agents"` with a name+model
table. Example:

```
agents (3)
  name             model
  Code Reviewer    glm/glm-4-flash
    Reviews PR diffs and flags style issues
  Summarizer       claude-sonnet-4
    Summarises long docs
  Test Writer      (default)
    Generates pytest cases
```

`/agent <name>` produces a `sideNote` of kind `"agent"` with:

```
agent: Code Reviewer
  path:  C:/Users/me/.minimax/agents/code-reviewer/agent.md
  desc:  Reviews PR diffs and flags style issues
  model: glm/glm-4-flash

--- body ---
You are a senior code reviewer ...
```

If the agent doesn't exist (`ok: false`), the TUI surfaces a `log` line
with the error message instead of an empty sideNote — same UX pattern as
`/trace <bad-id>`.

## Files changed

- `aethercode-tui/src/commands.ts` — `/agents` and `/agent <name>` cases
  in `handleSlash`; new entries in `SLASH_HELP` and `SLASH_COMMANDS`

## Tab-completion

Both new commands are in the `SLASH_COMMANDS` list, so Tab-completion
works:

- `/ag<Tab>` → `/agent`
- `/agents` completes in one shot (only one match for the full word)
- `/agent <Tab>` does NOT complete the agent name — completion only
  covers the command part, not arguments. The user types the agent
  name by hand (or pastes it).

## What doesn't ship in this round

- **TUI editor for agent bodies**: editing agent.md in the TUI would
  require a multi-line input mode plus a write-back RPC. The desktop
  AgentEditor is the canonical path; the TUI is read-only here.
- **TUI live agent picker**: there's no equivalent of the desktop's
  AgentEditorLazy in the TUI's right sidebar. Workflow `kind: agent`
  steps still take a free-text name (the user types `agent: <name>` or
  picks from a slash-popup list). A future R-round could mirror the
  desktop's drag-drop workflow editor into a TUI modal.

## Cross-project lesson

- Both the desktop (Tauri + React) and TUI (Ink + Node) talk to the
  same daemon via JSON-RPC. The wire shape is the contract; the UI is
  duplicated per surface. This is the same pattern R78-R82 set up
  for traces and metrics. R109-3-sync extends the pattern to agents.
