## 摘要

**终身学习**（也称持续学习或增量学习）是通过使系统**在动态环境中持续适应**来推进**人工通用智能（AGI）**的关键组件。尽管大语言模型（LLM）在自然语言处理方面展现了令人印象深刻的能力，但现有 LLM 智能体**通常被设计为静态系统**——缺乏响应新挑战而随时间适应的能力。本综述是**首篇系统总结将终身学习融入基于 LLM 的智能体的潜在技术**的工作。我们将这些智能体的**核心组件**分类为**三个模块**：
- **感知模块**：多模态输入整合
- **记忆模块**：存储与检索演化中的知识
- **行动模块**：与动态环境的锚定交互

我们强调这些支柱如何**共同实现持续适应、缓解灾难性遗忘并改善长期性能**。本综述为致力于在 LLM 智能体中开发终身学习能力的研究者与从业者**提供路线图**——涵盖新兴趋势、评估指标与应用场景的洞见。

## 1. 引言

### 1.1 构建终身学习 LLM 智能体的动机

**大语言模型（LLM）**的近期进展显著改变了自然语言处理领域。**GPT-4**等模型被设计用于通过从海量文本数据中学习来处理与生成类人文本。然而，**传统 LLM 在训练后是静态的**——这意味着它们一旦部署**就无法适应新任务或新环境**。它们的知识保持固定，且在不重训练的情况下难以整合新信息，限制了在动态真实场景中的适用性。

相比之下，**LLM 智能体**代表了 AI 的一种更先进形式——不同于处理输入文本并基于先前训练生成输出的标准 LLM，**LLM 智能体是能够与环境交互的自主实体**。这些智能体能**感知多模态数据**（文本、图像、传感器数据）、**将此信息存储在记忆中**，并**采取行动影响或响应其环境**。**被设计为持续适应新上下文**——LLM 智能体从其交互与经验中学习，**随时间改善其决策能力**。

将终身学习融入 LLM 智能体的动机源于开发智能系统的需求——该系统**不仅能适应新任务，还能在广泛的动态环境中保留与应用先前知识**。当前 LLM 智能体通常被开发为**静态系统**，限制了其响应新挑战而演进的能力。**大多数 LLM 终身学习研究聚焦于处理不断变化的数据分布而不与环境交互**——例如 LLM 的持续微调以适应特定领域的指令。然而，**这些方法仍将 LLM 视为静态黑盒系统，未解决 LLM 在真实环境中交互学习的实际需求**。

**图 2** 比较传统终身学习范式与本文讨论的 LLM 智能体与环境交互的**新范式**。**图 3** 展示终身 LLM 智能体如何通过交互适应环境并实现行为演化。**图 4** 展示在游戏、网页浏览、购物、家居任务与操作系统等多种环境中终身 LLM 智能体的应用。

## 3. 构建终身学习 LLM 智能体

### 3.1 终身学习的形式化定义

**定义 3.1（LLM 智能体的环境）**：我们将基于 LLM 的智能体环境建模为**目标条件部分可观察马尔可夫决策过程（POMDP）**。POMDP 定义为 8 元组 $\mathcal{E} = \langle \mathcal{S}, \mathcal{A}, \mathcal{G}, T, R, \Omega, O, \gamma \rangle$：

- $\mathcal{S}$：状态集合（每个状态可包含多模态信息——文本描述、图像、结构化数据）
- $\mathcal{A}$：动作集合（每动作代表智能体可发布的指令——常以自然语言表达）
- $\mathcal{G}$：可能的目标集合
- $T$：状态转移概率函数
- $R$：目标条件奖励函数（数值或文本反馈）
- $\Omega$：观察集合
- $O$：观察概率函数
- $\gamma$：折扣因子

**定义 3.2（基于 LLM 的智能体）**：智能体的策略 $\pi$ 是从观察到动作的映射。在每步 $t$：
- 智能体接收观察 $o_t$（文本、图像或其他结构化数据）
- 选择动作 $a_t$（通过基于 LLM 的策略 $\pi(o_t)$ 生成文本命令）
- 环境返回奖励 $r_t \in R(s_t, a_t, g)$

**定义 3.3（任务）**：任务 $T^{(i)} = \langle E^{(i)}, o_0^{(i)}, g^{(i)} \rangle$ 由环境、初始观察与特定目标组成。

**定义 3.4（轨迹）**：任务 $T^{(i)}$ 的轨迹 $\tau_{T_i}^{(i)} = \langle o_0, a_0, r_0, o_1, a_1, r_1, \ldots, o_{T_i}, a_{T_i}, r_{T_i} \rangle$。

**定义 3.5（试验）**：试验是智能体对任务的一次完整尝试——对应一条轨迹。

**定义 3.6（轨迹级 vs. 步骤级奖励）**：
- **轨迹级奖励**：仅最终结局产生信息性反馈
- **步骤级奖励**：中间动作也产生有意义的反馈

**定义 3.7（终身学习任务）**：$\mathcal{U} = \{T^{(1)}, T^{(2)}, \ldots, T^{(n)}\}$：
- **环境内**：所有任务共享相同底层环境结构
- **跨环境**：任务来自不同环境（需要跨域适应与迁移）

**定义 3.8（终身学习目标）**：寻找策略 $\pi$ 最大化所有任务上的期望性能：
$$\max_{\pi} \sum_{i=1}^{n} J(T^{(i)}, \pi) = \max_{\pi} \sum_{i=1}^{n} \mathbb{E}_{\tau_{T_i}^{(i)} \sim \pi} \left[ \sum_{t=0}^{T_i} \tilde{R}^{(i)}(o_t, a_t, g^{(i)}) \right]$$

### 3.2 终身学习背景与历史

**图 5** 展示终身学习在 AI 系统中的发展——4 个关键阶段：
1. **基础概念建立**（1980s 起）
2. **深度终身学习进展**（2010 至今）
3. **终身学习融入 LLM**（2020 起）
4. **LLM 智能体终身学习的最新发展**（2023 起）

**4 阶段方法分类**：
- **排练方法**（Rehearsal-Based）：回放先前数据子集
- **正则化方法**（Regularization-Based）：施加约束或惩罚防止重要参数大变化
- **架构方法**（Architecture-Based）：动态修改网络架构
- **表示方法**（Representation-Based）：学习鲁棒可迁移表示
- **提示方法**（Prompt-Based）：使用提示或辅助输入指导模型

**LLM 终身学习（2020-至今）**：包括**持续预训练、持续指令微调、持续对齐、持续知识编辑**。

**LLM 智能体终身学习（2023-至今）**：关键进展：
- **动态任务适应**
- **多模态整合**
- **记忆与知识管理**
- **强化学习整合**
- **外部知识整合**
- **更广泛的真实世界应用**

### 3.3 整体架构

终身学习 LLM 智能体的架构设计为**跨任务与环境持续适应、整合与优化其行为**。**我们识别三个关键模块——感知、记忆与行动——启用终身学习**。此划分遵循先前工作 [14] 的框架——一个显著差异是：我们采用"记忆"模块（[14] 中提出）而非"脑"模块——提供更清晰功能与改进模块化。

每个模块与其他模块交互以确保智能体**能处理新信息、保留有价值的知识、选择上下文相关的行动**。三个模块形成**动态反馈循环**：感知模块将新信息传递给记忆模块——在那里它被存储与处理——记忆模块然后指导行动模块——影响环境并通知未来感知。**图 6** 展示此整体架构——**图 7** 总结后续章节的组织。

## 4. 单模态感知

### 4.1 网页与图表环境

单模态感知（通常为文本）使智能体能在网页与图表等专门化环境中**发展深度领域特定知识**——理解网页、文本交互、专精任务。

### 4.2 游戏环境

游戏环境（文本 RPG、文本冒险）需要智能体维持长期上下文、记忆先前决策并适应新事件。

---

## 5. 多模态感知

### 5.1 新知识感知

多模态智能体整合**视觉、听觉、文本**——形成对环境的**更全面、更鲁棒**理解——对需要多模态上下文的任务（如机器人控制、多媒体分析）至关重要。

### 5.2 旧知识感知

智能体还必须利用先前学到的多模态模式——避免灾难性遗忘旧知识的同时整合新观察。

---

## 6. 工作记忆（Working Memory）

工作记忆代表智能体的**短期记忆**——负责处理**即时上下文**（如提示、用户输入、相关工作区信息）。它使智能体能**实时基于当前上下文行动**——为短期推理与决策提供基础。

- **6.1 提示压缩**：将长提示压缩为可管理表示
- **6.2 长上下文理解**：处理百万 token 级别的长上下文
- **6.3 角色扮演**：在多智能体场景中维持角色身份
- **6.4 自我纠正**：在多回合交互中识别与修正错误
- **6.5 提示优化**：迭代优化提示以改善智能体性能

---

## 7. 情景记忆（Episodic Memory）

情景记忆存储**长期经验与事件**（用户交互、过去任务结果、多回合对话）。情景记忆帮助智能体**回忆过去经验以改善未来行动**——同时维持长期行为的一致性与学习。

- **7.1 数据重放与特征重放**：回放先前任务的数据或特征
- **7.2 持续强化学习**：在持续到达的新任务上应用 RL
- **7.3 自我经验**：智能体从自身过去的成功与失败中学习

---

## 8. 语义记忆（Semantic Memory）

语义记忆充当**外部知识存储**——帮助智能体获取与更新世界知识。通过**持续知识图谱学习**与**持续文档学习**等机制——语义记忆促进新知识整合到智能体的内部框架中。

- **8.1 持续知识图谱学习**：随时间演化知识图谱
- **8.2 持续文档学习**：整合新文档到知识库

---

## 9. 参数化记忆（Parametric Memory）

参数化记忆**驻留在模型内部参数中**——不同于显式事件记忆。**参数变化**（通过微调或训练更新）**反映长期知识并贡献于智能体的通用知识库**。此记忆类型使智能体**跨任务保留知识而无需存储显式事件细节**。

- **9.1 持续指令微调**：增量指令微调
- **9.2 持续知识编辑**：在参数中编辑过时或不正确信息
- **9.3 持续对齐**：随时间维持人类价值对齐

## 10. 锚定行动（Grounding Actions）

### 10.1 锚定行动的挑战

锚定行动涉及将抽象决策转化为**环境中的具体动作**——如点击 UI 元素、生成响应、移动机器人。挑战包括：
- 跨模态锚定（视觉-语言对齐）
- 长期一致性
- 处理错误与异常

### 10.2 不同环境的解决方案

不同环境（网页、桌面、游戏、物理世界）需要**专门的锚定方法**：
- 网页：基于 DOM/截图的点击
- 桌面：GUI 元素识别
- 游戏：基于规则的智能体交互
- 物理：动作空间映射

---

## 11. 检索行动（Retrieval Actions）

### 11.1 从语义记忆检索

智能体从**外部知识库**（向量数据库、知识图谱、文档）检索相关信息——锚定响应于事实。

### 11.2 从情景记忆检索

智能体从**过去经验**（任务轨迹、对话历史）检索——改善长期一致性与学习。

---

## 12. 推理行动（Reasoning Actions）

### 12.1 情景内推理行动

**单次轨迹内的推理**——如 CoT、ToT、ReAct、Reflexion——支持任务内的多步决策。

### 12.2 情景间推理行动

**跨多轨迹的推理**——综合过去经验以改善未来决策——支持终身学习与适应。

---

## 13. 评估指标与基准

**第 13 节**呈现评估 LLM 智能体终身学习的指标与基准：
- **任务成功率**
- **灾难性遗忘率**（backward transfer）
- **知识迁移率**（forward transfer）
- **学习效率**（样本效率）
- **长期一致性**

## 14. 真实世界应用与用例

终身学习 LLM 智能体在**多种真实世界场景**中应用：
- **游戏**：长期一致的角色行为
- **网页浏览**：适应新网站与界面
- **购物**：长期用户偏好学习
- **家居任务**：设备管理 + 多模态理解
- **操作系统**：命令适配 + 工具发现
- **机器人**：物理世界适应
- **医疗对话**：长期患者交互

---

## 15. 关键挑战、限制与未来方向

**主要挑战**：
- **稳定性-可塑性两难**：保留旧知识 vs. 适应新任务
- **灾难性遗忘**：学习新任务时丢失旧知识
- **可塑性损失**：随时间失去适应新任务的能力
- **多模态整合**：跨模态对齐的复杂性
- **记忆管理**：长时程一致性 + 容量管理
- **评估标准化**：缺乏统一基准
- **真实世界部署**：安全、隐私、可靠性

**未来方向**：
- **统一终身学习理论**
- **更高效的持续学习算法**
- **多模态终身学习**
- **真实世界大规模评估**
- **人机协作终身学习**
- **安全、对齐与伦理**

## 16. 结论

本综述是**首篇系统总结将终身学习融入基于 LLM 的智能体潜在技术**的工作。我们形式化了 LLM 智能体终身学习的概念，将核心组件分类为**三个模块**（感知、记忆、行动），并讨论各模块下的关键方法。**终身学习 LLM 智能体代表迈向 AGI 的关键一步**——使系统能持续适应动态环境而无需重训练。**本综述为研究者与从业者提供路线图**——涵盖新兴趋势、评估指标与应用场景的洞见。
