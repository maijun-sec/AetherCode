# 2602.23720 The Auton Agentic AI Framework (Snapchat)

**作者**: Sheng Cao, Zhao Chang, Chang Li, Hannan Li, Liyao Fu, Ji Tang (Snap Inc.)

**日期**: 2026-02-27

**PDF**: 0.4 MB · 19 pages (white paper)

**核心**: **Auton Framework** = Cognitive Blueprint (declarative spec) + Runtime Engine (execution substrate), 解决 "Integration Paradox" — LLM 输出概率性 vs 后端需要确定性。

## 1. Architecture Pillars

| Pillar | 作用 |
|---|---|
| **AgenticFormat Standard** | Language-agnostic 声明式 schema (YAML/JSON), versionable |
| **Deterministic Governance** | Constraint Manifold — 行动前 policy projection, 不靠 post-hoc filter |
| **Cognitive Persistence** | Hierarchical memory (生物 episodic memory 启发) |
| **3-Level Self-Evolution** | In-context → meta-prompt → RL fine-tune |

## 2. Execution Model

**POMDP + Latent Reasoning Space**:
- Agent = POMDP actor
- Reasoning space 是 latent (非 observable)
- Action emission 受 Constraint Manifold 约束

## 3. Runtime 优化

- **Parallel graph execution**: 多个 tool call 并发
- **Speculative inference**: 预测下一步, 提前准备
- **Dynamic context pruning**: 动态剪 context, 省 token

## 6. 教训

- **Integration Paradox 是 LLM agent 核心矛盾** — 概率 vs 确定, 必须显式处理
- **Declarative + Runtime 分离** — 跟 IaC (Terraform/Kubernetes) 同理
- **Constraint Manifold 优于 post-hoc filter** — 在 action 前约束, 不在 action 后检查
- **3-Level evolution 是务实路径** — in-context (便宜) → meta-prompt (中等) → RL (贵)
- **Speculative inference 节省 token** — 跟 LLM serving 的 speculative decoding 同理
