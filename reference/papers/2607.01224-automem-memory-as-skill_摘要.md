# AutoMem: Automated Learning of Memory as a Cognitive Skill (2026)

- **ArXiv**: 2607.01224
- **作者**: Shengguang Wu, Hao Zhu, Yuhui Zhang, Xiaohan Wang, Serena Yeung-Levy (Stanford)
- **类别**: Memory & Continual Learning
- **提交**: 2026-07-01

## 摘要 (中文)

记忆专长 (memory expertise) 是一种习得的技能: 知道要编码什么、何时检索、如何组织知识 — 这在认知科学中称为元记忆 (metamemory)。我们把这一视角带到 LLM: **把记忆管理当作可训练的技能**。把文件系统操作提升为与任务同等地位的第一类记忆动作, 让模型自己决定如何管理记忆。这个 "记忆技能" 沿两个轴线提升: (1) **支持它的结构** (prompt、文件 schema、动作词汇); (2) **使用它的模型熟练度**。两个轴线都抗拒手动优化: 长程任务跑数千步, 单个记忆错误可能隐藏很久才显现, 人审完整 trajectory 不现实。

AutoMem: 一个自动化两轴线的框架。**外循环 1**: 强 LLM review 完整 agent trajectory, 迭代修正 memory 结构 (scaffold)。**外循环 2**: 从多个 episode 中识别 agent 自己的好记忆决策, 作为训练信号直接提升模型熟练度。

实验: 3 个程序生成的长程游戏 (Crafter / MiniHack / NetHack), 只优化记忆 (不修改 task-action 行为) — 基础 agent 性能提升 2-4×, 让 32B 开源权重模型可与 Claude Opus 4.5 / Gemini 3.1 Pro Thinking 竞争。

## 核心观点 (给工程用的 3 条)

1. **"记忆是技能不是 buffer"**: 跟传统 "vector store + top-k" 不同, memory 是 agent 主动管理的对象. 这意味着 memory 应该有: (a) first-class action (read/write/search), (b) skill-evaluable policy (哪种 read 策略好), (c) trainable through feedback.
2. **"双轴线优化" (scaffold + proficiency)**: 不是单一维度优化. scaffold = 文件结构/prompt 模板; proficiency = 模型用 scaffold 的熟练度. 任何 memory 优化框架都需要同时考虑两者.
3. **"少即是多" 实证**: 只优化 memory (不优化 task action), 2-4× 性能. 这跟 AEL (2604.21725) 一样反直觉 — 加更多机制 (planner evolution / per-tool selection / skill extraction) 反而降低性能. 瓶颈是 "自我诊断如何使用经验", 不是架构复杂度.
