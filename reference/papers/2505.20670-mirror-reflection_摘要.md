# 2505.20670 MIRROR: Multi-agent Intra- and Inter-Reflection for Optimized Reasoning in Tool Learning

**作者**: Zikang Guo, Benfeng Xu, Xiaorui Wang, Zhendong Mao (USTC + Metastone)

**日期**: 2025-05-27 (v2)

**PDF**: 0.97 MB · 15 pages

**核心**: 把 reflection 拆成 **Intra-Reflection (action 前)** + **Inter-Reflection (action 后)**, 仿人脑 "先思后行 + 行后复盘"。

## 1. 问题

现有 reflection (e.g. Reflexion) **只在 action 后**复盘, 三大问题:
1. 阻止不了首次错误
2. 不可逆操作风险 (delete / send / pay)
3. trial-and-error 学习成本高

## 2. MIRROR 双层 reflection

| 类型 | 时机 | 作用 | 形式 |
|---|---|---|---|
| **Intra-reflection** | action **执行前** | 在每个 agent 内部, 评估 "我的决策会导致什么坏结果?" | preventive |
| **Inter-reflection** | action **执行后** | 在 agent 之间, 根据 observation 调整 trajectory | corrective |

仿人: 人类决策前会 mental simulation (intra), 行后会复盘 (inter)。

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|

## 6. 教训

- **Reflection 不仅是 "行后复盘"** — 行前 mental simulation 更省成本
- **不可逆操作必须有 intra-reflection** — delete / send / pay 不能事后后悔
- **Intra + Inter 互补** — Intra 拦首错, Inter 修漏网
- **Multi-agent 协作是 reflection 的天然载体** — agent 之间天然形成 inter-reflection
