## 一、一句话摘要

以"形式—功能—动态"三角框架，系统梳理 AI 智能体记忆研究。

## 二、背景与动机

近年来，基于大语言模型（LLM）的 AI 智能体在深度研究、软件工程、科学发现等领域取得显著进展。**记忆（Memory）** 是其区别于静态 LLM 的核心能力之一——它使智能体能够跨会话、跨任务维护信息、累积经验、保持身份一致性，是迈向通用人工智能（AGI）不可或缺的基础组件。然而，"记忆"在传统 LLM 语境下被简化为 KV 缓存与上下文窗口，并未触及智能体跨任务持续学习、长期人格保持、环境演化跟踪等深层需求。

当前"智能体记忆"研究存在两大突出问题。其一，**分类法过时**：现有综述的分类体系成型于 2025 年方法学爆发之前，未能反映 2025 年涌现的记忆框架、记忆增强的测试时缩放方法、记忆管理强化学习化等新方向；其二，**概念碎片化**：研究者对"智能体记忆"的理解差异巨大，陈述性/情景/语义/参数化记忆等术语被混用，缺少统一的概念框架，论文之间难以进行横向比较。

为此，本文构建了一套系统的"**形式—功能—动态**"三角分析框架，旨在调和既有定义、衔接新兴趋势、阐明记忆机制的基本原理，并以此对 200+ 篇文献进行统一坐标定位。

## 三、核心方法：形式—功能—动态三角

本综述以统一的"形式—功能—动态"三角组织全部内容：**形式**回答"什么承载着记忆"，**功能**回答"智能体为何需要记忆"，**动态**回答"记忆如何形成、演化、检索"。

### 3.1 形式：三种主流记忆形态

| 形式 | 特征 | 典型方法 | 适用场景 |
|------|------|---------|---------|
| **词元级记忆**（Token-level） | 符号化、可寻址、透明；快速增删改 | MemGPT、Mem0、A-MEM、Zep、G-Memory | 聊天机器人、个性化助手、高风险领域（法律/金融/医疗） |
| **参数化记忆**（Parametric） | 隐式、抽象、可泛化；更新慢但性能好 | MemoryLLM、M+、WISE、KnowledgeEditor | 角色扮演、数学/编码/游戏等推理、风格化响应 |
| **潜在记忆**（Latent） | 隐式、机器原生；密度高、可跨模态 | MemoryLLM、M+、MemGen、MemoryBank | 多模态智能体、边缘部署、隐私敏感场景 |

**词元级记忆**按拓扑复杂度细分为三类：扁平记忆（1D，无显式拓扑，按序列或"袋子"累积，代表为 MemGPT、Reflexion）、平面记忆（2D，单层结构化布局，树或图，代表为 A-MEM、HippoRAG、MemTree）、层次记忆（3D，多层互联结构，金字塔或多层图，代表为 Zep、GraphRAG、HiAgent）。

**参数化记忆**按存储位置细分为两类：**内部参数化记忆**直接调整模型原始参数，覆盖 pre-train / mid-train / post-train 三阶段；**外部参数化记忆**采用附加参数集（Adapter、LoRA、辅助 LM 等），不改原模型权重。

**潜在记忆**按状态来源细分为三类：**生成**（由辅助模型合成新潜在表征）、**复用**（直接继承先前 KV 缓存等计算状态）、**转换**（压缩、剪枝、改造已有潜在状态）。

> 关键洞察：三种记忆形式各有优势与局限。多模态、隐私敏感场景偏潜在记忆；高风险、可解释需求场景偏词元级记忆；强推理、风格化任务偏参数化记忆。

### 3.2 功能：三种记忆目的

| 功能 | 回答的问题 | 时间属性 | 细分 |
|------|----------|---------|------|
| **事实性记忆** | "智能体知道什么？" | 长期 | 用户事实性 + 环境事实性 |
| **经验性记忆** | "智能体如何提升？" | 长期 | 案例型 + 策略型 + 技能型 + 混合型 |
| **工作记忆** | "智能体此刻在想什么？" | 短期 | 单轮 + 多轮 |

**事实性记忆（Factual Memory）** 是智能体的"陈述性知识库"，记录关于用户、环境的可验证事实，确保交互的一致性、连贯性、适应性。借鉴认知科学的情景/语义记忆二分法，但在工程上以"事件流 → 摘要/反思/实体提取 → 知识图谱"连续处理谱形式落地，下分**用户事实性记忆**（MemoryBank、AI Persona、Mem0、RMM，记录身份、偏好、日常习惯、历史承诺）与**环境事实性记忆**（HippoRAG、Zep、MetaGPT、Generative Agents，记录文档状态、工具能力、其他智能体信息）。

**经验性记忆（Experiential Memory）** 是智能体的"程序性知识"，从历史轨迹中抽象可复用经验以支持持续学习与自我演化。按抽象层级分为四类：**基于案例**（Memento、ExpeL、Synapse、MapCoder，原始轨迹与解决方案作为示例直接回放）、**基于策略**（Reflexion、AWM、Buffer of Thoughts、ReasoningBank、H²R，高层策略、模板、工作流，从经验中蒸馏的认知脚手架）、**基于技能**（Voyager、Darwin Gödel Machine、CREATOR、Alita，可执行函数、API、MCP 协议、代码片段，将策略操作化为可调用能力）、**混合型**（ExpeL、G-Memory、Memp、LARP）。

**工作记忆（Working Memory）** 是智能体的"动态工作面板"，在有限上下文窗口内主动管理、操控信息：**单轮工作记忆**（LLMLingua、AutoCompressor、VideoAgent，处理长文档/多模态流的输入凝练与观察抽象）；**多轮工作记忆**（MEM1、ReSum、HiAgent、Context-Folding、DeepAgent、PRIME，长程交互中的状态维护、层次折叠、认知规划）。

> 认知科学锚点：三种功能分别对应人类记忆理论中的陈述性记忆、非陈述性记忆（程序性 + 习惯系统）、以及 Baddeley 工作记忆模型。但智能体版本具备生物对应物所缺乏的能力——可内省、可编辑、可版本化。

### 3.3 动态：记忆生命周期的三个过程

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  记忆形成    │  →   │  记忆演化    │  →   │  记忆检索    │
│ Formation   │      │ Evolution   │      │ Retrieval   │
└─────────────┘      └─────────────┘      └─────────────┘
       ↑                                          │
       └──────────── 反馈闭环 ───────────────────┘
```

**（1）记忆形成（Memory Formation）**——从原始数据提取有长期效用的知识，5 种操作：
- **语义摘要**：MemGPT、MEM1、ReadAgent、LightMem（长对话 → 全局摘要）
- **知识蒸馏**：TiM、RMM、AgentRR、MEM-α（从轨迹提取可复用知识）
- **结构化构建**：KGT、Mem0^g、GraphRAG、AriGraph、Zep（组织为图/树等拓扑）
- **潜在表征**：MemoryLLM、M+、MemGen、CoMEM（编码为向量或 KV 状态）
- **参数内化**：MEND、ROME、MEMIT、CoLoR（通过 SFT/RL 直接写入模型权重）

**（2）记忆演化（Memory Evolution）**——维护记忆库的质量，3 种机制：
- **整合**（Consolidation）：RMM、PREMem、AgentFold（合并新旧记忆，合成高层洞察）
- **更新**（Updating）：MemGPT、Zep、Mem-α、MemoryLLM（解决冲突、修订过时信息）
- **遗忘**（Forgetting）：MemGPT、XMem、KARMA、MemOS、Livia（剪枝冗余/过时信息）

**（3）记忆检索（Memory Retrieval）**——从记忆库获取相关知识，4 个步骤：
- **时机与意图**：MemGPT、ComoRAG、PRIME、MemGen、MemOS、H-MEM（何时触发、检索哪个记忆库）
- **查询构建**：Visconde、HyDE、MemoRAG、Auto-RAG（分解或重写查询以更好匹配索引）
- **检索策略**：Mem0、Zep、HippoRAG、Memory 3（BM25 词法、向量语义、图遍历、生成式、混合）
- **后检索处理**：RCR-Router、Memory-R1、ComoRAG、G-Memory（重排序、过滤、聚合、压缩）

## 四、实验结果

作为一篇系统性综述，本文的"实验结果"体现在其覆盖广度与概念贡献上，而非单一基准的数值对比。

**覆盖规模**：全文汇总 7 大类代表性方法、11 张分类表、2 张基准/框架总表，覆盖近 200 篇参考文献；配套论文列表仓库持续维护（截至 2026 年 1 月已收录 200+ 篇），形成可演化的开放资源。

**概念辨析**：系统厘清智能体记忆与 LLM 记忆、RAG、上下文工程之间的区别与重叠。早期"LLM 记忆机制"（如 MemoryBank、MemGPT）在当代视角下实为智能体记忆的早期实例；现代 RAG 系统与智能体记忆的边界日益模糊，需以任务域（单次推理 vs. 持续交互）作务实区分。

**新分类法**：提出"形式—功能—动态"三视角的多维分类体系，超越传统长/短期二分法。论文给出的关键结论之一：记忆不是辅助存储机制，而是使能智能体实现时间连贯性、持续自适应与长程能力的本质基质。

**对照表 1：智能体记忆 vs. 相邻概念**

| 概念 | 关系 | 关键区别 |
|------|------|---------|
| LLM 记忆 | 几乎完全被智能体记忆涵盖 | 智能体记忆强调跨任务、环境驱动演化；LLM 记忆聚焦模型内部 KV/上下文管理 |
| RAG | 技术栈重叠（向量检索、图检索） | RAG 服务单次推理的静态知识访问；智能体记忆是持续演化的认知状态 |
| 上下文工程 | 工作记忆机制有大量重叠 | 上下文工程是资源管理范式；智能体记忆是认知建模范式 |

## 五、局限与未来工作

本文提出的八大研究前沿即代表当前领域的局限与未来方向：①记忆检索转向生成式记忆（上下文自适应、跨异构信号集成、可学习且自优化）；②自动化记忆管理（自组织、自适应结构，显式工具调用集成进决策循环）；③RL × 智能体记忆（RL-free → 部分 RL 化 → 完全 RL 驱动的演化路径）；④多模态记忆（全模态支持仍为开放问题）；⑤多智能体共享记忆（从中心化共享到主动管理、自适应集体表征）；⑥世界模型中的记忆（SSM、显式记忆库、稀疏记忆三条路径，"数据缓存"→"状态模拟"）；⑦可信记忆（隐私保护、可解释性、幻觉鲁棒性三大支柱）；⑧人类认知连接（离线整合、生成式重构替代逐字回放）。

## 六、工程解读

对于 AetherCode 项目的工业级 Agent 框架落地，本综述提供了多重可借鉴的设计思想：

**已被借鉴（17 个 Tier-3 兼容实现中可见映射）**：
- **GlobalPlan** 与综述中"工作记忆 → 多轮工作记忆"高度同构：层次折叠、认知规划正是处理长程任务的核心机制。建议在下一版本引入 MEM1、ReSum 的周期性状态压缩范式，将当前的全量上下文保留改造为"摘要 + 关键事件索引"双轨结构。
- **RetrievalBandit** 直接对应"记忆检索 → 检索策略"小节——BM25、向量、图遍历、生成式、混合五类策略可视为 bandit 算法的臂空间，下一步可参考 Memory-R1 的 RL 驱动检索调度，让系统自主学习何时调用何种检索器。
- **ByzantineDetector** 与"可信记忆"小节（隐私保护、可解释性、幻觉鲁棒性）天然耦合，建议引入类操作系统的分段、版本控制、可审计抽象，使记忆操作具备反事实推理能力。

**可立即做的下一步**：
1. 在 AetherCode 中加入 MemoryLLM / M+ 风格的潜在记忆通道，专用于多模态智能体子任务；
2. 参考 RMM / Mem-α 的强化学习化思路，将记忆管理由手工规则改造为端到端可学习组件；
3. 在 World Model 子模块（若已存在）中借鉴 SSM + 显式记忆库 + 稀疏检索三路并行的设计；
4. 建立 8 大前沿中"多智能体共享记忆"的 PoC，验证从显式消息传递向中心化共享记忆迁移的可行性。

**重要提醒**：智能体记忆 ≠ 上下文工程，二者关注点不同。AetherCode 当前若以"长上下文 + RAG"为主线，建议按本综述的"任务域（单次推理 vs. 持续交互）"重新评估边界，避免重蹈概念混淆的覆辙。
