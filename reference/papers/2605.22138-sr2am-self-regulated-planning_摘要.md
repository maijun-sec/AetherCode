# 2605.22138 SR2AM: Self-Regulated Simulative Reasoning Agentic LLM

**作者**: Eric P. Xing, Jinyu Hou 等 (MBZUAI + Petuum)

**日期**: 2026-05-21 (v1)

**PDF**: 0.7 MB

**核心**: **SR2AM** — 把 agent 决策拆成 3 系统: System I reactive + System II simulative + System III self-regulation, 用 world model + learned configurator 控制 planning。

## 1. 3 系统

| System | 角色 | 状态 |
|---|---|---|
| **System I (Reactive)** | 细粒度 action | 标准 LLM 直执行 |
| **System II (Simulative)** | 未来状态预测 (world model) | LLM as world model |
| **System III (Self-Regulation)** | 决定何时 + 多深 planning | learned configurator |

## 2. 关键数据

| 任务 | v0.1-8B | 跟 120-355B 比 | 跟 685B-1T 比 |
|---|---|---|---|
| Math | Pass@1 接近 | 持平 | 持平 |
| Science | Pass@1 接近 | 持平 | 持平 |
| Tabular analysis | Pass@1 接近 | 持平 | 持平 |
| Web info seeking | Pass@1 接近 | 持平 | 持平 |

**v1.0-30B** uses **25.8-95.3% fewer reasoning tokens** vs comparable agentic LLMs

**RL 效果**: planning horizon +22.8%, planning frequency only +2.0% (学会往前看, 不是更频繁 plan)

## 3. 关键洞察

- **Self-regulation 关键** — 不是每次都要 planning, learned configurator 决定
- **World model 用 LLM 自己** — 不需单独训
- **小模型 + 智能 planning > 大模型 + 暴力 plan**

## 6. 教训

- **3 系统分离** 是 agent 决策的关键架构
- **Self-regulation 学会往前看**, 不是更频繁
- **小模型 + 智能 planning > 大模型 + 暴力 plan** — 跟 MAKER / ICLR paper 共识
- **25-95% token 节省** 验证 approach 实用
- **LLM as world model** 简化架构, 不必单独训练
