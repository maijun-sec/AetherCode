# 2605.14892 Beyond Individual Intelligence: LIFE Progression Survey

**作者**: Shihao Qi, Jie Ma 等 17 人 (西安交大 + Lenovo + Sydney + 华中师大)

**日期**: 2026-05-14 (v1) / 2026-05-15 (v2)

**PDF**: 12 MB · 89 pages (comprehensive survey)

**核心**: 提出 **LIFE Progression** 4 阶段框架 — Lay / Integrate / Find faults / Evolve, 揭示多 agent 系统从能力建设到自我进化的因果依赖链。

## 1. LIFE 4 阶段

| 阶段 | 含义 | 代表工作 |
|---|---|---|
| **Lay foundation** | 单 agent 能力建设 (planning / memory / tool) | ReAct, Reflexion, Voyager |
| **Integrate via collaboration** | 多 agent 协作机制 | AutoGen, MetaGPT, ChatDev |
| **Find faults via attribution** | 错误归因诊断 | AgentEval, TRAIL, Where2Edit |
| **Evolve via self-improvement** | 自主进化 | Self-Refine, AutoAgent, Voyager++ |

**关键洞见**: 各阶段之间有**因果依赖** — 没有稳固 foundation, integration 易崩; 没有 fault attribution, evolution 难闭环。

## 2. 4 阶段间 cross-stage open challenges

- **Lay → Integrate**: 单 agent 能力怎么 API 化给多 agent 共享
- **Integrate → Find**: 多 agent 通信中错误怎么定位到具体 agent
- **Find → Evolve**: 归因结果怎么转化为训练信号
- **Evolve → Lay**: 进化后能力怎么反哺到 foundation

## 5. 教训

- **LIFE 4 阶段是完整闭环** — 缺任何一阶段, 多 agent 难自我进化
- **Cross-stage 反馈是关键** — single-stage 优化已饱和, 跨阶段耦合是未来
- **Attribution 是 evolution 的前提** — 没归因, 进化方向不可控
- **Survey 的价值是建立 framework** — 89 页 survey 浓缩成 4 阶段 framework, 跟 UMM 8 能力形成对照
