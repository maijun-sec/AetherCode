## 摘要

大语言模型（LLM）的进展推动了**主体性**（agency）研究的浪潮——**推理、规划与行动**的能力。这一努力已产生围绕强大 LLM 主干的**智能体化框架**——编排感知、记忆与决策。随着大**多模态模型（LMM）**的出现，这些系统能处理与整合**多样化的模态**（包括图像、音频与视频）——从而改善其真实世界适用性。然而，**虽然基于 LLM 的智能体综述已存在，但多模态在塑造主体性中的角色在近年来未被系统性地检视**。本综述通过分析**多模态在智能体化框架核心功能模块中（感知、推理、规划、记忆与行动）的影响来填补这一空白。通过此视角，我们追溯**从文本中心智能体到多模态框架的演进**，检视**模态如何通过委派、晚期融合与早期融合架构被整合**，评估**由锚定感知与多模态推理启发的智能体化行为**的出现。我们通过**模态中心分类法**组织现有工作——该分类法将**架构设计选择链接到智能体能力**。此外，我们**综述跨多个应用领域的多模态智能体化系统**——包括**机器人、GUI 与网页导航、多媒体内容生成与编辑、长视频理解与检索**。超越能力，我们**分析这些设置下的性能**并讨论**效率-可扩展性权衡**——包括**训练与推理成本、延迟与部署约束**。通过聚焦多模态在智能体化设计中的影响，我们旨在识别**关键空白**并规划**通往鲁棒通用智能系统的路线图**。

## 1. 引言

LLM 的进展推动了**主体性**（推理、规划、行动）研究的浪潮，催生了围绕强大 LLM 主干编排感知、记忆与决策的智能体化框架。LMM 的出现使这些系统能处理与整合**多样化模态**（图像、音频、视频）——提升真实世界适用性。

**本综述的关键贡献**：
- **多模态在智能体化框架核心模块中的影响分析**（感知、推理、规划、记忆、行动）
- **从文本中心到多模态框架的演进追溯**
- **模态整合架构分析**：委派、晚期融合、早期融合
- **模态中心分类法**：将架构设计选择链接到智能体能力
- **跨应用领域综述**：机器人、GUI 与网页导航、多媒体内容生成与编辑、长视频理解与检索
- **性能 + 效率-可扩展性权衡分析**：训练/推理成本、延迟、部署约束
- **关键空白识别与未来路线图**

## 2. 智能体化框架的基础

### 2.1 编排器（Orchestrator）

编排器是智能体化系统的**中央决策组件**——协调感知、推理、规划、记忆与行动。

#### 2.1.1 推理（Reasoning）

推理是智能体化系统**分析信息、推导结论、做出决策**的能力。在多模态环境中，推理可能涉及：
- **语言推理**：基于文本的逻辑推导（CoT、ToT）
- **视觉推理**：图像/视频中的空间-时间关系理解
- **跨模态推理**：整合文本、视觉、音频的联合推理

#### 2.1.2 规划（Planning）

规划将复杂目标分解为可执行子任务：
- **层次化任务网络**（HTN）
- **思维树**（ToT）
- **反应式规划** vs. **深思式规划**
- **多模态规划**：考虑视觉/音频输入的规划

#### 2.1.3 记忆（Memory）

记忆使智能体能跨交互保留信息：
- **短期记忆**：上下文窗口
- **长期记忆**：外部向量数据库
- **情景记忆**：过去事件的多模态记录
- **统一记忆**：跨模态对齐的记忆

### 2.2 感知（Perception）

感知是智能体化系统**理解环境**的能力。在多模态环境中，感知涵盖：
- **视觉感知**：图像理解、目标检测、场景理解
- **音频感知**：语音识别、声学事件检测
- **视频感知**：动作识别、时序理解
- **多模态融合**：跨模态对齐与整合

### 2.3 行动（Action）

行动是智能体化系统**影响环境**的能力：
- **数字行动**：GUI 操作、网页导航、API 调用
- **物理行动**：机器人动作、具身交互
- **混合行动**：跨数字-物理边界的复合行动

### 2.4 模态（Modalities）

智能体化系统可能处理的模态：
- **文本**：自然语言
- **图像**：静态视觉
- **视频**：时序视觉
- **音频**：语音、声学
- **3D**：点云、网格
- **传感器**：LiDAR、IMU、触觉
- **跨模态**：组合多模态输入

## 3. 分类法（Taxonomy）

### 3.1 多模态感知策略

#### 3.1.1 委派感知（Delegated Perception via Tool Calling）

LLM 智能体**调用专门的感知工具**（视觉模型、OCR、检测器）——不直接处理原始模态数据。优势：解耦、灵活；劣势：延迟、工具错误传播。

#### 3.1.2 晚期融合感知（Late-Fusion Perception）

**每种模态由独立模型处理**——特征或决策在最后阶段融合。优势：模块化；劣势：跨模态交互受限。

#### 3.1.3 早期融合感知（Early-Fusion Perception）

**在早期阶段跨模态融合**特征——捕获细粒度跨模态交互。优势：丰富跨模态理解；劣势：架构复杂、计算密集。

### 3.2 多模态推理与规划

#### 3.2.1 基于语言的推理

以**文本**为主要推理介质——其他模态被转换为文本描述。

#### 3.2.2 视觉锚定推理

推理**锚定于视觉观察**——空间、时序、关系理解。

#### 3.2.3 跨模态推理

联合推理多种模态——整合文本、视觉、音频证据。

### 3.3 多模态记忆架构

#### 3.3.1 模态特定记忆

**每种模态有独立记忆系统**——视觉记忆、文本记忆、音频记忆。

#### 3.3.2 统一记忆

**跨模态对齐到共享表示**——通过 CLIP-style 嵌入空间。

#### 3.3.3 时序上下文管理

**管理时序数据流**——长视频、多回合对话、持续监控。

#### 3.3.4 带宽管理

**优化多模态数据的存储与检索**——压缩、摘要、选择性保留。

### 3.4 多模态行动空间

#### 3.4.1 语言驱动行动

行动以**自然语言指令**形式表达——执行器解释为具体动作。

#### 3.4.2 视觉锚定行动

行动以**视觉证据**为条件——点击特定 UI 元素、操作特定对象。

#### 3.4.3 具身多模态行动

在**物理或模拟环境**中执行多模态感知-行动循环。

### 3.5 评估方法

- **任务成功率**
- **多模态理解质量**
- **长时程一致性**
- **真实环境泛化**

## 4. 应用

### 4.1 纯文本应用

纯文本 LLM 智能体（无视觉/音频）——作为**多模态智能体的基线**。

### 4.2 机器人与物理具身

**多模态机器智能体**——整合视觉、触觉、LiDAR、IMU、音频：
- **导航**：VLN（视觉-语言导航）
- **操作**：抓取、装配、护理
- **多机器人协作**：协调多物理智能体

### 4.3 GUI 与网页导航

**视觉+语言智能体**在数字环境中操作：
- **网页导航**：WebArena、Mind2Web
- **桌面 GUI 操作**：OSWorld、ScreenAgent
- **移动 UI**：AndroidWorld

### 4.4 多媒体内容生成与编辑

**多模态生成智能体**——创造与编辑图像、视频、音频：
- **图像生成**：DALL-E、Stable Diffusion + LLM 规划
- **视频生成**：Sora + 智能体编排
- **音频合成**：MusicLM + 智能体控制
- **多模态编辑**：从指令到多模态输出的转换

## 6. 效率

效率分析覆盖**训练成本、推理成本、延迟、部署约束**四个维度。

### 6.1 训练成本

- **模型规模 vs. 任务性能**：扩展规律
- **多模态预训练**：视觉编码器 + LLM 主干的联合训练成本
- **数据规模与多样性**：训练 token 与多模态样本

### 6.2 推理成本

- **单次推理的 token/计算消耗**：多模态融合的额外开销
- **早退策略**：置信度足够时提前停止
- **缓存与重用**：中间结果缓存

### 6.3 延迟

- **端到端响应时间**：感知 → 推理 → 行动
- **关键路径优化**：并行感知与推理

### 6.4 部署约束

- **边缘 vs. 云端**：模型大小与延迟权衡
- **流式响应**：实时应用的流式架构
- **多模态 I/O 延迟**：视频/音频流的缓冲

## 10. 局限

本综述的**关键局限**：

- **多模态评估缺乏统一基准**：不同基准测量的能力维度不同，难以横向比较
- **模态组合的指数级扩展性挑战**：N 种模态的组合数为指数级
- **真实世界部署中的安全/隐私/伦理问题**：多模态输入可能引入新的攻击面
- **长期评估与可复现性困难**：多模态环境的随机性使结果难以复现
- **训练数据偏差**：多模态预训练数据可能包含社会偏见
- **跨文化泛化**：当前基准多以英语/西方场景为主

## 12. 结论

跨领域的证据表明存在一个一致的模式：多模态智能体最大的提升来自**感知与推理的更紧密集成**，而非仅仅扩大模型规模。在机器人领域，紧凑的端到端系统可以胜过将感知与动作分离的更大流水线。在复杂的数字环境（如网页导航）中，当前智能体仍远未达到人类级别的可靠性，特别是对于需要精确控制和错误恢复的任务。

这些发现也对效率与部署有明确启示：原生大型多模态模型虽然提供强大的零样本能力，但其对**重 token 推理**的依赖引入了延迟与成本，限制了实际可扩展性。相比之下，**领域特定与微调架构**提供了更可持续的权衡。OpenVLA (Kim et al., 2024) 和 CogAgent (Hong et al., 2024) 等系统表明，较高的训练成本可以通过降低推理延迟和改进长期效率来摊销。

类似的原则适用于高带宽场景（如长视频生成），其中基于检索的设计（如 VideoAgent (Wang et al., 2024e) 和 VLog (Lin & Shou, 2025)）以及冻结的主干网络减少了冗余计算。总体而言，这表明未来的进步将**更少依赖于构建越来越大的通用模型**，而**更多地依赖于为交互任务量身定制的有效、扎根于场景的架构**，特别是在可靠性与响应性至关重要的场景中。
