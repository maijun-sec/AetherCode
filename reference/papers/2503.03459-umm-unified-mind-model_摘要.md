**核心**: **UMM (Unified Mind Model)** — 基于 Global Workspace Theory 的认知架构, 8 大认知能力 (perception / planning / reasoning / tool use / learning / memory / reflection / motivation), 给出 LLM agent 设计的理论框架。

## 1. 理论基础

**Global Workspace Theory** (Baars 1988): 意识是大脑多个 specialist module 的全局共享广播 (global broadcast)。每个 module 处理专门任务, 通过 global workspace 共享信息。

**应用 LLM**:
- 每个 LLM agent = 1 个 specialist module
- Global workspace = agent 之间的 message bus
- 意识 = message 被 broadcast 到所有 module 的状态

## 2. 8 大认知能力

| 能力 | 含义 | AetherCode 对应 |
|---|---|---|
| **Multi-modal perception** | 多模态输入 (text/image/audio) | `aethercode-tools` StandardTools 17 tool |
| **Planning** | 任务分解为 plan | `DagPlan` |
| **Reasoning** | 推理 (chain-of-thought) | `Verifier` + LLM |
| **Tool use** | 调外部 tool | `StandardTools` + `McpRegistry` |
| **Learning** | 从经验学习 | `ExperienceRecord` + `ForgettingPolicy` |
| **Memory** | 长期/短期/感知 | `Blackboard` + memory module |
| **Reflection** | 自我反思 | `SelfCorrectionLoop` |
| **Motivation** | 内部驱动 (reward / goal) | `CostCeiling` + workflow goal |

## 3. MindOS: Agent-building Engine

基于 UMM 实现的无代码 agent 构建工具, 用户拖拽配置 8 大能力, 生成 domain-specific agent。

## 4. 关键洞察

| 洞察 | 含义 |
|---|---|
| **Agent 是 specialist module** | 不是 monolithic, 是组合 |
| **Global workspace = message bus** | Agent 间通信, 不是直连 |
| **8 能力都要有** | 缺一个, agent 能力不完整 |
| **LLM 适合做 reasoning + reflection** | 其他能力需要外部 tool 支持 |

## 7. 教训

- **8 能力是 LLM agent 完整集** — 缺哪个, 哪个就是薄弱点
- **Global workspace 比直连好** — 降低 N² 通信, broadcast 一次到位
- **LLM 强项是 reasoning + reflection** — 弱项是 perception + tool 编排, 需 tool 补
- **MindOS / 无代码是商业化方向** — 工程实现是次要, 框架设计是核心
- **Motivation 是被忽视能力** — 大部分 framework 没 motivation, UMM 显式纳入
