# 2603.13256 REDEREF: Training-Free Probabilistic Control for Multi-Agent LLM Systems

**作者**: Mohammad Parsa Hosseini, Ankit Shah, Saiyra Qureshi, Alex Huang, Connie Miao, Wei Wei

**日期**: 2026-02-24 (v1)

**PDF**: 0.66 MB · 13 pages

**核心**: **REDEREF** — training-free controller, 用 **Thompson sampling** + **reflection-driven reroute** + **memory-aware priors** 改进多 agent 路由效率。

## 1. 4 核心机制

| 机制 | 作用 |
|---|---|
| **Belief-guided delegation** | Thompson sampling 选历史贡献正向的 agent |
| **Reflection-driven rerouting** | LLM judge 评估后, 改路由 |
| **Evidence-based selection** | 不平均 output, 选有证据的 |
| **Memory-aware priors** | 减少 cold-start 低效 |

## 2. 关键数据

- Token 用量 -28%
- Agent call 数量 -17%
- Time-to-success -19%
- Agent / judge 退化时优雅 fallback

**对比**: recursive retry alone 饱和, 加 belief-guided routing 才有效。

## 3. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| Thompson sampling 选 agent | ⚠️ 当前无 probabilistic 路由 | 缺 |
| Reflection-driven reroute | `SelfCorrectionLoop` (R-radar-7) | ✅ |
| Evidence-based selection | `CritiqueStrategy` (N proposer + M critic) | ✅ |
| Memory-aware priors | `ExperienceRecord` (历史 score) | ✅ |

## 4. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|
| `ThompsonSamplingRouter` | 多 agent 路由, Thompson sampling 选 agent | `orchestration.router` |
| `BeliefState` | Agent 贡献分布, Beta 分布 | `orchestration.router` |
| `ReflectionDrivenRerouter` | 路由失败时, LLM judge 决定改路由 | `orchestration.selfcorrect` |
| `TrainingFreeController` | 整合 4 机制, 不训练 | `orchestration.controller` |

## 5. 教训

- **Probabilistic 路由优于 deterministic** — Thompson sampling 探索-利用平衡
- **Token / call / time 三 axis 同时省** — 路由优化多 axis 增益
- **Reflection reroute 是 fallback 机制** — 失败时不重试, 改路由
- **Memory priors 缓解 cold-start** — 不必每个任务都从零学
- **Training-free 性价比高** — 比 RL fine-tune 省 10× 资源
- **recursive retry alone 饱和** — 必须加智能路由
