# ERL: Experiential Reflective Learning for Self-Improving LLM Agents (2026)

- **ArXiv**: 2603.24639
- **作者**: Marc-Antoine Allard, Arnaud Teinturier, Victor Xing, Gautier Viaud (Illuin Technology)
- **类别**: Self-Improvement / Memory
- **提交**: 2026-03

## 摘要 (中文)

LLM 驱动的 agent 在复杂推理和多步问题解决上越来越强, 但它们**难适应专门环境**, 不利用过去的交互 — 每次新任务都从零开始。我们引入 **Experiential Reflective Learning (ERL)**, 一个通过体验学习实现快速环境适应的简单自改进框架。ERL 反思 task trajectory 和结果生成 heuristics, 捕获跨任务可迁移的可操作经验。测试时, 基于当前任务检索相关 heuristics 注入 agent context 引导执行。

Gaia2 benchmark (Search + Execution splits): ERL 提升 ReAct baseline 7.8% 成功率, 大幅提升任务完成可靠性, 超过先前体验学习方法。消融发现: **选择性检索至关重要**; heuristics 提供比 few-shot trajectory prompting 更可迁移的抽象。

## 核心观点 (给工程用的 3 条)

1. **Heuristics > raw trajectories**: ERL 反思后提取 heuristics (高层可迁移规则), 不是原样存 trajectory. 对比 AutoMem (2607.01224) 保留 granular details, ERL 偏 aggregate. 两种思路互补: heuristics 给 general guidance, trajectories 给 specific 案例.
2. **"Single-attempt trajectories" 也能用**: 跟 ExpeL / AutoGuide 不同, ERL 不需要 paired trajectories 或多次 rollouts. 单次 attempt → reflection → heuristic. 部署成本低, 适合 production.
3. **"Selective retrieval" 关键**: 早期工作 (ExpeL) 把所有 insights 串到 prompt, 不可扩展. ERL 用 LLM 对每个新 task 评分 stored heuristics 选 top-k. 给 MemoryCriticAgent 加 "scored retrieval" 有可走路径.
