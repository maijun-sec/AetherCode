# 2606.06787 AdMem: Advanced Memory for Task-solving Agents

**作者**: Runzhe Wang (Princeton) + Amazon + Arm

**日期**: 2026-06-05 (v1)

**PDF**: 1.0 MB

**核心**: **AdMem** — Bi-level (短/长期) + 3 memory 类型 (semantic / episodic / procedural) 统一框架, actor / memory / critic 三 agent 协同。

## 1. 3 Memory 类型

| 类型 | 含义 | 例子 |
|---|---|---|
| **Semantic** | 事实知识 | "API X 需要 token Y" |
| **Episodic** | 经验 | "上次调用失败因 Z" |
| **Procedural** | 流程 | "如何做 task W" |

**Bi-level**: 短期 (in-context) + 长期 (external store)

## 2. Multi-agent 架构

- **Actor agent**: 执行任务
- **Memory agent**: 维护 3 类 memory
- **Critic agent**: reward 评估 + 标记低质量 memory

## 3. 关键特性

- **Reward-based evaluation**: Critic 给 memory 打分, 高分晋升, 低分剪枝
- **Merging**: 相似 memory 合并去重
- **Pruning**: 长期不用的 memory 剪掉

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| Semantic memory | `MemoryExtractor` 部分 | ✅ |
| Episodic memory | `ExperienceRecord` | ✅ |
| Procedural memory | ⚠️ 缺, 现有 `MemorySnapshot` 偏 raw | 缺 |
| Critic agent | `SelfCorrectionLoop` (部分) | ✅ |
| Merging + pruning | `MemoryConsolidator` + `MemoryDeduplicator` | ✅ |
| Reward-based | `MemoryAudit` + sensitivity | ✅ |

## 6. 教训

- **3 memory 类型 (semantic/episodic/procedural) 是 完整集** — 缺一不可
- **Bi-level (LT/ST) 是必要架构** — 短期 in-context + 长期 store
- **Critic agent 是 LLM agent 的常驻组件** — 不能省
- **Reward-based memory governance** — 不是所有 memory 都保留, 高分晋升
- **跟 ALMA 互补** — AdMem 是手工 3-type, ALMA 自动发现
