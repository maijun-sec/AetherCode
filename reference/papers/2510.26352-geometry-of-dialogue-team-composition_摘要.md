# 2510.26352 The Geometry of Dialogue: Graphing LLMs to Reveal Synergistic Teams

**作者**: Kotaro Furuya, Yuichi Kitagawa (Hitachi R&D)

**会议**: AAAI-26 Workshop on LaMAS (Oral)

**日期**: 2025-10 (v1)

**PDF**: 2.2 MB · 9 pages

**核心**: **Interaction-Centric Team Composition** — 通过两两对话的 embedding 构建 "language model graph", 用社区检测发现协同 cluster, 自动化多 agent 团队组建。

## 1. 问题

- 多 agent 团队组建传统靠 task-driven (top-down), 缺 model 内在关系
- Model 内在不透明 (闭源 API, 训练数据保密)
- 手工 curated team 难 scale

## 2. 3 阶段方法

```
1. 生成 pairwise 对话
   ↓
2. 构建 language model graph (基于对话 embedding)
   ↓
3. 社区检测 → 协同 model cluster
```

**关键**: 不需要先验知识 (架构 / 训练数据 / 任务性能), 纯靠对话行为发现。

## 3. 关键发现

- 发现的 cluster 跟 model 已知 specialization **一致** (e.g. code-focused, math-focused)
- Primed conversation 发现的 team 在 downstream benchmark 上**超过 random baseline**
- 跟手工 curated team **准确率相当** — 自动方法可达人类水平

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| Pairwise embedding 找 cluster | `Blackboard` (cross-agent 共享 KV) | 部分 |
| 社区检测 → 协同 team | `MultiAgentOrchestrator` (5 strategy) | ✅ |
| 不需先验 | AgentCard 描述能力 (功能化) | ✅ |
| Primed conversation | `GlobalPlan` (GoalAct 风格) | ✅ (R-paper-batch3) |

## 5. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|
| `LanguageModelGraph` | 节点=model, 边=对话 embedding 距离 | `aethercode-bridge` |
| `SynergisticTeamFinder` | 社区检测, 输出 cluster 列表 | `aethercode-bridge` |
| `TeamCompositionReport` | 跟手工 curated team 对比, 给优化建议 | `evals.teams` |

## 6. 教训

- **Interaction 行为 > 架构先验** — 对话 embedding 暴露的 specialization 跟人手工一致
- **自动化 team composition 可达人类水平** — 减少手工调优成本
- **Pairwise 对话是关键数据** — 单个 prompt 不够, 要多轮对话
- **社区检测是经典 graph 算法** — Louvain / Leiden 可直接用
