# 2601.07577 TDP: Task-Decoupled Planning for Long-Horizon Agents

**作者**: Yunfan Li, Bingbing Xu 等 (中科院计算所)

**日期**: 2026-01 (v1)

**PDF**: 1.0 MB

**核心**: **TDP (Task-Decoupled Planning)** — 把任务分成 DAG sub-tasks, 每个 sub-task context 隔离, 减少 82% token 消耗。

## 1. 问题

- Long-horizon 任务中, 单一 growing context 混合多 sub-task 信息
- 信息干扰 + error ripple
- ReAct (step-wise) 短视; one-shot planning brittle

## 2. TDP 3 模块

| 模块 | 作用 |
|---|---|
| **Supervisor** | 全局任务分解 → DAG, 监控 progress |
| **Planner** | 单 sub-task 高层 plan, 只看当前 node + 前置 node 结果, **不传全局 history** |
| **Executor** | sub-task 内 action 执行, 触发 local replan |

**关键**: Planner 上下文严格隔离, 不继承 sibling sub-task 信息。

## 3. Self-Revision

- Sub-task 完成后, 检查是否违反全局假设
- 如违反: 加新 node / 删过时 node / refine pending node spec
- 保持全局 feasibility, 避免不必要的 global replan

## 4. 关键数据

- 任务成功率提升
- **Token 消耗 -82%** (vs entangled context)
- Error ripple 显著减少

## 5. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| Supervisor (decompose) | `CentralPlanner` (R-paper-batch4) | ✅ |
| Planner (per sub-task) | `GlobalPlan` (R-paper-batch3) | ✅ |
| Scoped context | `Blackboard` 共享 + per-task memory | ✅ |
| DAG sub-tasks | `DagPlan` | ✅ |
| Self-Revision | ⚠️ 无显式 revision mechanism | 缺 |

## 6. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|
| `ScopedContext` | 严格隔离 per sub-task context | `orchestration.planner` |
| `TaskDecoupledPlanner` | 整合 Supervisor + Planner + Executor | `orchestration.planner` |
| `SelfRevisionHook` | sub-task 完成后检查 + revise DAG | `orchestration.planner` |
| `DAGContextPruner` | 自动剪掉无关 sub-task context | `orchestration.planner` |

## 7. 教训

- **Token -82%** 巨大节省, 验证 scoped context 价值
- **Context isolation 跟 Function parameter scoping 思想一致** — 只传需要的
- **Self-Revision 是关键** — 不强求 global replan
- **DAG sub-tasks 跟 CentralPlanner + GlobalPlan 已覆盖** — 差 Self-Revision
- **跟 GoalAct 协同** — TDP 的 Supervisor 跟 GoalAct 的 Global Plan 高度互补
