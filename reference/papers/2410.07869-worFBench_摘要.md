# 2410.07869 WorFBench: Benchmarking Agentic Workflow Generation (ICLR 2025)

**作者**: Shuofei Qiao, Runnan Fang, Zhisong Qiu, Xiaobin Wang, Ningyu Zhang, Yong Jiang, Pengjun Xie, Fei Huang, Huajun Chen (Zhejiang University + Alibaba)

**会议**: ICLR 2025 · arXiv 2024-10-10 (v3)

**PDF**: 3.3 MB · 25 pages

**核心**: **WorFBench + WorFEval** — 第一个**复杂图结构 workflow 生成 benchmark**, 用 subsequence + subgraph matching 量化 LLM 的 workflow planning 能力。

## 1. 问题

| 现有 workflow eval 问题 | WorFBench 解法 |
|---|---|
| Holistic 性能 only, 不知哪步错 | 细粒度 step-level subsequence match |
| 简单 DAG / linear | 复杂图 (branch / loop / parallel) |
| 评测标准 lax | subgraph matching 严格对齐 |
| 场景覆盖窄 | 6 大场景 (data analysis / web / code / reasoning / etc.) |

## 2. 关键发现

- **Sequence planning vs graph planning gap ~15%** — 即便 GPT-4 在 sequence plan 强, 复杂图 plan 弱 15%
- 生成的高质量 workflow 可直接喂给下游 agent, **推理时间更短、准确率更高**
- Fine-tune 后的开源 7B 模型在 hold-out 任务上 **泛化能力接近 GPT-4**

## 3. WorFEval 三层评测

| 层级 | 指标 | 适用 |
|---|---|---|
| **Holistic** | 端到端 success rate | 整体 |
| **Subsequence** | step-level 顺序匹配 | sequence plan |
| **Subgraph** | 图结构对齐 (节点 + 边) | graph plan |

## 4. AetherCode 关联

| 论文观点 | AetherCode 对应 | 实现状态 |
|---|---|---|
| 复杂图 workflow 表达 | `DagPlan` 节点+边 | ✅ |
| Subsequence / Subgraph 评测 | ⚠️ 当前只有 holistic 评测 | 缺 |
| Workflow 喂下游 agent 加速 | `WorkflowEngine` execute | ✅ |
| Fine-tune 提升泛化 | R-sdk 测真 Workflow class | ✅ |

## 5. 兼容实现候选

| 类 | 用途 | 文件位置 |
|---|---|---|
| `SubsequenceMatchMetric` | step-level 顺序匹配 (WorFEval 风格) | `evals.metrics` |
| `SubgraphMatchMetric` | 节点 + 边对齐, 复杂图评测 | `evals.metrics` |
| `WorkflowReplayer` | 把 plan 喂给 AgentRuntime 跑, 测端到端 | `evals.e2e` |

## 6. 教训

- **Holistic metric 掩盖 step-level 错误** — subsequence 评测能定位哪步崩
- **Sequence vs Graph plan 能力差 15%** — LLM 在复杂图上弱
- **生成的 workflow 可被下游 agent 复用** — 不是只用一次, 是 reusable artifact
- **Subgraph matching 是图结构评测的关键** — 不是 string match
